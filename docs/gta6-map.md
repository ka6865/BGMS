# GTA6 서브 지도

`/gta6`는 GTADB의 커뮤니티 추정 지도를 사용하는 독립 콘텐츠다. 한국어·영어·ID 검색, 분류 필터, 즐겨찾기, 방문 체크, 장소 링크 공유를 제공한다. 한국어 명칭·지역명은 검색용 음역/번역이며 공식 번역으로 확정하지 않는다.

## 좌표와 타일

원본 world 좌표 `(x, y)`를 Leaflet `CRS.Simple`의 `(lat, lng) = (y - 16384, x + 16384)`로 바꾼다. Leaflet 줌 0에서 원본 줌 5의 32768px 평면에 대응한다. `zoomOffset=5`, `minNativeZoom=-5`, `maxNativeZoom=0`을 사용한다. 파일 경로는 `{z}/{z},{y},{x}.jpg`이며 z=5 범위는 행 21~99, 열 21~103이다. 줌 0보다 확대하면 기존 타일을 확대하며, -5보다 축소하면 원본 줌 0을 축소한다. Leaflet 줌 -4 미만에서는 이름이 있는 장소를 우선 표시해 마커 겹침을 줄이고, 확대하면 이름 미확인 장소까지 표시한다. 선택한 장소는 항상 표시한다.

오른쪽 설명판은 표시 영역을 world X=3500(원본 픽셀 X=19884)에서 잘라 제외한다. 경계 타일에도 줌별 CSS 클리핑을 적용해 이동·축소 중 설명판이 다시 나타나지 않게 한다. 원본 파일·장소 좌표·하단 출처 표시는 유지하며, 현재 좌표가 있는 장소 3,340개는 모두 표시 영역 안에 있다. 원본 갱신 시 설명판 경계와 동쪽 끝 장소를 함께 재검증한다.

## 한국어 표시와 입력

이름이 있는 933개 장소 중 354개에 비공식 한국어 이름을 제공한다. 이름 번역은 기존 ID 별칭과 정확히 일치하는 이름 사전으로 제한하며, 나머지 이름과 `?` 등 추정 표기는 원문을 유지한다. 76개 지역·주소 항목을 번역해 3,340개 중 3,325개의 표시 주소를 보완했다. `address`·`originalName`은 원문, `displayAddress`·`name`은 표시용이며 한글과 영문 모두 검색된다. 상세 화면에서 원문 이름과 접을 수 있는 원문 주소를 확인할 수 있다.

주요 6개 지역은 원본 타일을 바꾸지 않고 한글 레이블을 겹쳐 표시한다. `MAP_REGIONS.coordinates`는 변환 전 world `[x, y]`이며 경계나 확정 장소 위치를 뜻하지 않는 표시용 근사 중심이다. 상세 확대에서는 레이블을 숨긴다.

Leaflet의 휠 입력 누적을 사용하며 `zoomSnap=0`, `zoomAnimation=false`, `wheelDebounceTime=16`, `wheelPxPerZoomLevel=20`으로 설정한다. 기본 확대 애니메이션 중 추가 목표 배율이 반영되지 않는 지연을 제거하고, Mac의 스크롤 정규화 이후 확대 폭을 보완한다. 버튼·키보드의 한 단계 확대와 모바일 터치 입력은 Leaflet 동작을 유지한다.

현재 화면 경계에 15% 여유를 둔 장소만 그리며 선택 장소는 항상 표시한다. 마커를 memo 처리하고 좌표·스타일·이벤트 참조를 유지해 같은 반경 구간의 작은 배율 변화에서 기존 마커를 다시 설정하지 않는다. 이동이 끝나면 새 화면의 마커를 추가한다.

## 로컬 저장과 공유

- 저장 키: `bgms:gta6:progress:v1`
- 형식: `{ version: 1, favorites: string[], visited: string[] }`
- ID를 기준으로 저장하므로 원본 갱신에서 순서가 바뀌어도 기록이 유지된다. 현재 데이터에서 사라진 ID는 목록·개수에서 제외한다.
- 저장소가 차단되면 화면 상태를 유지하고 영구 저장이 되지 않을 수 있음을 알린다. 손상·지원하지 않는 버전은 빈 목록으로 읽는다.
- 공유 주소: `/gta6#L25`. 새로고침과 뒤로/앞으로 가기를 지원한다. 존재하지 않거나 좌표 없는 ID는 안내한다.
- 방문 기록은 게임이나 계정과 동기화하지 않는다. 신규 DB·API·외부 서비스 쓰기는 없다.

## 갱신

별도 임시 폴더에서 원본을 sparse checkout한다. 앱 저장소에 원본 `.git` 폴더를 넣지 않는다.

```bash
git clone --filter=blob:none --depth 1 --sparse https://github.com/rolux/gtadb.org /tmp/bgms-gta6-upstream
git -C /tmp/bgms-gta6-upstream sparse-checkout set map/data/6 'maps/tiles/6/yanis,17'
git -C /tmp/bgms-gta6-upstream rev-parse HEAD
```

가져온 commit과 변경 내용을 검토한 뒤 해당 JSON·타일만 복사하고 manifest의 commit·날짜·해시·수량을 갱신한다. 타일 버전이 바뀌면 새 디렉터리로 추가하고 지도 URL과 좌표 보정을 함께 바꾼다. 기존 버전 삭제와 운영 배포는 별도 작업이다. 데이터 라이선스와 사진 원본의 권리를 같은 것으로 취급하지 않는다.

```bash
npm run verify:core
npx vitest run tests/gta6-map.test.ts tests/gta6-map-ui.test.ts tests/home-hub.test.ts
npm run test:unit
```

브라우저에서 검색·분류·빈 결과·데이터 재시도·타일 재시도·선택/공유·즐겨찾기/방문 저장을 확인한다. 최소 뷰포트는 375x667, 390x844, 430x932와 데스크톱이다. 실제 iOS/Android 기기 검증과 웹 뷰포트 검증을 구분한다.

- `npm run verify:core`: Node 24, `NODE_OPTIONS=--max-old-space-size=4096`에서 통과. 기존 경고 43건, 오류 0건.
- 전체 Vitest: `vitest run --maxWorkers=4 --testTimeout=20000`, 519개 파일 통과, 7,045개 테스트 통과, 조건부 388개 skip.
- 데이터·홈·독립 레이아웃 및 재검증: 6개 파일 55개 통과. 초기 전체 실행은 자원 경합과 수정 중 회귀 테스트가 섞여 실패했으며, 코드 고정 후 전체 재실행으로 확인했다.
- 격리 Chrome: 375x667, 390x844, 430x932, 1440x900에서 문서 가로/세로 넘침 없음. 검색·분류·빈 결과·장소 선택·즐겨찾기/방문 reload 유지·실제 클립보드 복사·공유 ID와 뒤로/앞으로·데이터 503 후 재시도 통과. 정상 시 GTA6 자산 HTTP 오류와 JS 오류 0건.
- 추가 경계 검증: 타일 503 후 재시도와 localStorage 차단 안내 통과. 홈도 동일한 4개 뷰포트에서 GTA6 진입과 가로 넘침 없음을 확인했다.
- 원본 타일 행/열 전도는 실제 z=5 파일명 전체를 비교하는 회귀 테스트로 수정했다. 타일 확대/축소와 선택 툴팁은 브라우저에서 확인했다.
- iOS Safari/Android WebView·실기기, 운영 배포, 3D·게임 진행도 동기화는 검증/구현 범위 밖이다.

## 설명판 표시 영역 조정 검증

원본 설명판 제외와 모든 3,340개 장소 보존, native 줌 -5~0의 경계 타일 크롭을 단위 테스트로 검증했다(7개 통과). `verify:core` 통과. 375x667·390x844·430x932·1440x900에서 렌더링, 확대·이동·전체 보기, 동쪽 끝 장소 선택을 확인했으며 자산 HTTP 오류·JS 오류는 없었다. 실기기 검증과 운영 배포는 수행하지 않았다.

## 한국어·트랙패드 브라우저 검증

375x667·390x844·430x932·1440x900에서 한글 지명, 한영 장소 표시, 검색, 즐겨찾기/방문 reload 유지, 지도 크롭과 문서 넘침 없음을 확인했다. 모의 일반 휠·Ctrl 휠은 각각 입력 10개가 확대 10회에 반영됐으며 첫 확대 종료까지 20~22ms였다. 개선 전 같은 작은 입력은 애니메이션 때문에 확대 2회에 반영됐고 첫 확대 종료까지 약 300ms였다. 작은 배율 변화에서 기존 마커의 `setLatLng`·`setStyle` 호출은 모두 0회였다. 수치는 로컬 개발 서버·격리 Chrome에서의 관측이며 실제 Mac 트랙패드/Safari 측정이나 보장 수치가 아니다. 화면 캡처와 입력 보고서는 Git 제외 대상 `tmp/gta6-qa/korean-*`에 보관한다.

이번 변경의 `verify:core`는 Node 24에서 통과했다(기존 경고 43건, 오류 0건). GTA6 데이터·마커 UI·홈·독립 경로 단위 검사 4개 파일 38개 통과, 독립 리뷰의 Critical/Important 지적은 없었다. 전체 Vitest는 이번 격리 변경에서 재실행하지 않았다.

## 공략 게시판(/gta6/guides)

운영자가 콘솔이 없어 PC판 출시 전에는 게임 내용을 검증할 수 없다. 장소 데이터는 gtadb 원본 재수집으로 갱신하고, 공략·가이드는 유저 글로 쌓는다.

- 저장: 기존 게시판 `posts`에 분류 `GTA6 공략`(`lib/gta6/guides.ts`)으로 저장한다. migration·API 변경은 없고 글쓰기 Turnstile·작성 쿼터·sanitize·신고·추천을 그대로 쓴다.
- 화면: 목록 `/gta6/guides`는 자체 화면, 상세·글쓰기는 게시판 컴포넌트를 GTA6 레이아웃 안에서 재사용한다. 다른 분류 글을 `/gta6/guides/{id}`로 열면 `/board/{id}`로 308 이동한다. 작성·수정·삭제 후 이동 경로는 `postBasePath(category)`로 정한다.
- 배그 게시판 목록(`/board`, 모바일 앱 `/api/mobile/board/posts`)에서는 `GTA6 공략` 글을 빼고 분류 탭도 두지 않는다. 글은 `/board/{id}`로도 열리지만 canonical은 `/gta6/guides/{id}`다. 홈 "최근 소식"에는 남고 링크는 `/gta6/guides/{id}`로 간다.
- 광고: 지도(`/gta6`)는 광고 없이 두고, 공략 게시판은 일반 게시판처럼 광고 스크립트를 싣는다.
- 신뢰: 운영자는 스팸·욕설만 관리하고, 내용의 정확성은 추천·댓글로 커뮤니티가 판단한다는 안내를 목록 상단에 둔다.

## 검색·공유 정보

- `/gta6`, `/gta6/guides`는 GTA6 전용 openGraph·twitter 정보와 `public/gta6/og.jpg`(1200×630)를 쓴다. 이 이미지는 YANIS v17 타일(z=2)을 이어 붙여 바이스 시티 주변을 잘라내고 글자를 얹은 변경본이며, 이미지 안에 gtadb.org CC BY 4.0 출처를 적었다. Rockstar 로고나 공식 이미지는 쓰지 않는다.
- 지도 목록 하단 "GTA6 지도 소개"는 서버 HTML에 포함되는 실제 본문이다. 지역 이름은 `MAP_REGIONS`, 장소 수는 `manifest.locatedCount`에서 가져온다.
- `/gta6`에 WebPage(about VideoGame)·BreadcrumbList JSON-LD를 넣는다.
- `GTA6 공략` 분류 글의 canonical은 `/gta6/guides/{id}`이고, 기본 공유 이미지는 GTA6 이미지다.
- 장소별 개별 페이지는 추정 위치 기반이라 내용이 얇아 만들지 않는다. PC판 출시 후 데이터가 확정되면 검토한다.
