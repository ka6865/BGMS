# 무기 메타 패치별 조회 전환

사용자 요청에 따라 이전 기준/현재 검증 선택을 제거했다. 전후 숫자는 보관된 일반전·경쟁전의 PC(steam/kakao) 경기 기록을 직접 집계한다. 예전 보고서의 기준 선택 UI 설명은 이 변경으로 대체된다. 기존 strict benchmark RPC와 원본 증거 버전은 바꾸지 않는다.

## 조회와 보존

- 패치 목록은 DB `weapon_meta_patches`에서 가져온다. 기본값은 가장 최근 등록된 패치이고 과거 패치를 선택할 수 있다.
- 패치 전: 해당 점검 시작 직전 14일. 패치 후: 적용 시작부터 다음 패치 점검 시작 전까지. 모든 등록된 점검 구간은 제외한다. 실제 미래 경기는 집계하지 않는다.
- 기존 `patch_version` 라벨과 무관하게 `played_at`으로 조회한다. 따라서 이전 패치 후 기록을 다음 패치 전 비교에 재사용하면서 원본을 복사하거나 바꾸지 않는다.
- 새 기록/재분석은 DB 트리거가 경기 날짜에 맞춰 패치 라벨을 지정한다. 정적 환경변수가 이전 버전이어도 이후 경기의 라벨은 갱신된다. 조회는 라벨에 의존하지 않는다.
- 데이터는 쌓일 수 있으므로 과거 기간에서도 늦게 수집한 경기나 재분석한 값은 반영된다. 기간이 고정되는 것이며 결과를 불변 스냅샷으로 고정하는 것은 아니다.
- 원본 과거 데이터 R2 백업은 기존 복구 보고서 참조. 정기 백업 대상에 표본 테이블과 패치 목록을 포함했다. 이 정기 백업 변경은 코드 배포 후 반영된다.

## 43.1 준비 및 다음 패치 등록

공식 PC 일정: 2026-09-10 09:00~17:30 KST. https://www.pubg.com/ko/news/11057
현재 카탈로그의 43.1 시작 시각은 공식 점검 종료 **예정** 시각이다. `timing_status=scheduled`로 화면에도 예정이라고 표시한다. 점검 연장/조기 종료 시 공식 확인 후 `starts_at`을 수정하고 종료가 확인되면 `timing_status=confirmed`로 바꾼다. 예정 시간은 자동으로 실제 종료 확인으로 승격하지 않는다. 시각 수정 후 조회는 원본 재작성 없이 재계산된다.

다음 패치도 운영자가 공식 PC 점검 시작/종료 시각과 출처를 카탈로그에 등록한다. 사용자에게 추가 작업을 요구하지 않으며, 새 버전을 등록하면 이전 패치 조회 종료 구간과 새 패치 선택지가 자동 반영된다. 패치노트 발행일을 서비스 적용일로 추측하거나 콘솔 일정을 PC에 적용하지 않는다. 자동 패치 일정 수집이나 관리자 편집 UI는 이번 변경에 포함하지 않았다.

42.3은 기존에 쓰던 2026-08-12 12:00 KST 기준을 유지한다. 다른 공식 시각으로 임의 변경하지 않았다.

## 추가 오류 수정

`GasPump`에 포함된 `UMP`가 SMG로 오분류되는 환경 폭발 5행을 발견했다. 기존 행은 보존하고 새 공개 집계에서 제외한다. 수집 단계 `categorizeWeapon`도 보강해 재발을 막았다. 게임 유형 미확인 기록 역시 보존하지만 비교에는 포함하지 않는다. 표본 없는 기간은 수치 0 대신 자료 없음으로 표시한다.

## 검증

- 패치 전후 및 점검 경계, 이전 기록 재사용, 늦은 재분석의 라벨, 경기 유형 분리, 주유기 제외: 실제 DB 트랜잭션 fixture를 service_role로 통과 후 ROLLBACK.
- 기존 엄격한 기준/보존 데이터 구분 RPC 회귀 fixture도 통과 후 ROLLBACK.
- 패치 당일 일별 추세의 전·후 분모를 분리하고 차트에서도 구분했다. 다른 패치에 선택 총기가 없으면 유효한 전체 선택으로 돌아간다.
- API/UI/수집/백업 관련 54개 테스트 통과. 정적 타입·lint 및 프로덕션 빌드 확인.
- 실제 로컬 API와 모바일/데스크톱 패치 선택을 점검. 43.1 적용 전이므로 실제 패치 후 경기 유입 검증은 아직 불가하다.
- 변경은 develop 로컬 코드와 공유 DB migration에 적용했다. 웹 배포/커밋/푸시는 별도로 진행한다.
