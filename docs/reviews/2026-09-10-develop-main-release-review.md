# develop → main 배포 전 전체 변경 리뷰

비교 기준은 `origin/main`의 `9884f5b`. develop에 있던 커뮤니티 수집 구현과 미커밋 AI 코칭 검토·사람 승인 큐·무기 메타 변경을 함께 검토했다. 검토 범위는 코드, 테스트, SQL, workflow 및 운영 문서다.

## 사용자에게 보이는 변경

- 무기 메타: 기준 선택 대신 42.3/43.1 패치 선택, 보관 표본 직접 조회, 점검 제외, 과거 기간 유지, 패치 당일 그래프 전후 분리. 43.1은 적용 예정 상태이며 이후 실제 수집 경기부터 비교한다.
- 관리자 AI 코칭 품질: 개별 경기/최근 10경기/스쿼드 실응답 15개를 검토하고 승인·보류·제외 및 교정 이력을 관리한다. 운영 분석 자동 변경이나 파인튜닝을 실행하지 않는다.
- 커뮤니티: 수집·근거 검증·글/답글 초안 작성 후 운영자가 항목별 승인한다. Discord 검토와 관리자 페이지 이동을 지원한다. 기존 중복 패치노트 cron route는 제거하고 GitHub Actions의 CLI 경로를 유지한다.

## 리뷰에서 수정한 내용

1. CI 자리표시자 DB 환경 때문에 무기 메타의 미설정 테스트가 외부 요청을 시도하던 문제: 테스트가 필요한 환경을 직접 격리한다.
2. outbox 테스트의 광범위 `Function` 타입 lint 오류를 구체 타입으로 변경했다.
3. 커뮤니티 SQL 네 파일은 실제 운영 migration과 해시가 동일함을 확인하고 로컬 파일명/참조를 실제 적용 버전에 맞췄다.
4. 관리자 자동화 안내와 운영 문서에 남은 자동 발행 설명을 현재의 항목별 승인 절차로 수정했다.
5. 답글 실패/기한 만료 안내는 자동 재생성을 약속하지 않고 원문 게시글에서 운영자가 직접 대응하도록 명시했다. 댓글별 한 번 생성·중복 방지 정책은 유지한다.
6. Discord 버튼 승인 후 메시지 수정 실패도 공통 복구 함수로 처리해 `discord_decision_update_failed`를 저장하고 worker가 재시도하도록 연결했다. 회귀 테스트로 기록 보존을 검증했다.

## 검증 근거

- GitHub Actions와 같은 자리표시자 환경에서 전체 Vitest: 233개 파일, 2,805개 통과. 기존 조건부 76개 제외.
- `npm run verify:core`: 오류 0, 기존 경고 40. TypeScript 통과.
- `npm run build`: 프로덕션 빌드 통과.
- 일회용 PostgreSQL 17에서 community/review SQL 시나리오와 동시 승인·중복 게시·중지 경합·수동 재시도 검사 통과.
- 공유 DB: 필요한 migration 및 AI 검토 15개, 패치 목록 존재 확인. 설정된 BGMS AI 일반 계정이 정확히 1개이며 자동 발행은 꺼져 있다.
- 무기 메타 실제 API: 두 패치 × 전체/일반전/경쟁전 6개 조합 확인. 시간 경계·과거 재사용·권한 fixture는 롤백 검증. 모바일 375/390/430과 데스크톱 1440 확인은 무기 메타 보고서에 기록했다.
- 커뮤니티 백엔드, 관리자/API, 무기·패치노트의 독립 리뷰를 수행하고 발견한 운영상 결함을 수정했다.

## 배포 조건과 범위

PR의 마지막 커밋에 대한 CI와 Vercel 배포 확인 후 merge한다. 커뮤니티 예약은 기존 환경/변수 설정을 따르며, 이번 검증에서 실제 글·답글 공개 또는 Discord 메시지 발송을 실행하지 않았다. Discord 실환경 연결/예약 활성화는 별도 운영 절차다.

로컬 pnpm 설정 두 파일은 저장소의 기존 npm 배포에 포함하지 않고 보존한다. 다른 worktree의 미커밋 작업은 변경하지 않는다.
