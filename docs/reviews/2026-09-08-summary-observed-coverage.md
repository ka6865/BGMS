# 최근 최대 10경기 AI 분석: 관측 범위와 수치 일치 보강

## 범위와 결론

최근 최대 10경기 요약 API와 토론 카드의 지표를 점검했다. 카드 후보는 기존처럼 최신 유효 최대 10경기 → 점수 상위 최대 5경기 → 주력 모드 경기다. 개별 경기 분석 엔진, 스쿼드 시너지 API, 2D·3D 리플레이는 변경하지 않았다.

기존에는 카드의 선택 경기 수를 모든 증거 행에 반복했다. 실제 지표별 확인 경기 수가 달라도 같은 수가 표시되는 문제를 수정했다. 부분 기록에서 성공률을 잘못 계산하는 경로도 재현 후 보강했다.

## 발견 및 수정

| 항목 | 기존 경로 | 수정 |
| --- | --- | --- |
| 주도권 성공률 | 시도 표본은 있으나 성공률이 NULL인 경기를 실패로 합산 | 표본 수와 유효 성공률을 함께 확인한 경기만 계산. 발생 표본 0은 비율 계산 불가 유지 |
| 1:1 승률 | 승·패 중 하나가 누락돼도 나머지를 전체 합계에 더함 | 같은 경기의 승·패가 모두 확인된 경우만 합산 |
| 솔로 킬 비중 | 솔로·클린업·팀원 기여 중 누락값을 0으로 더함 | 세 구성값이 모두 확인된 경기만 구성 비율에 포함. 구성 합계 0은 기회 없음으로 표시 |
| 지표별 경기 수 | 카드에 선택된 경기 수를 지표의 표본처럼 표시 | `evidence.userMatchCount`로 각 지표의 확인 경기 수를 제공 |
| 일부 누락된 전체 합계 | 전체 합계를 보류하지만 이유가 불분명함 | ‘선택된 4경기 중 3경기만 기록이 확인되어 전체 합계·비율을 표시하지 않습니다’ 표시 |
| 백업 시간 미측정 | 일반적인 기록 없음 설명 | 복수 처치 성공 수가 실제 0인 경우 성공 사례가 없어 시간을 계산할 수 없다고 설명 |

주도권 재현 테스트에서는 정상 경기의 성공 2/시도 2에 성공률 NULL·시도 2인 경기를 더하면 **50%**가 됐다. 수정 후 정상 관측 경기의 **100%, 1경기 기록 확인**을 유지한다. 이는 누락 경기를 성공으로 추정한 것이 아니라 계산에서 제외한 결과다. 실제 관측된 실패 0%와 사용 0회는 계속 보존한다.

관측 경기 수는 해당 지표의 필수 기록이 확인된 경기 수다. 복수·연막 성공률과 전체 사용 합계는 기존의 전체 관측 요구를 유지한다. 일부 기록만 합쳐 전체 합계처럼 제시하지 않는다. 비율과 평균 중 부분 관측으로 계산 가능한 항목에는 그 확인 경기 수를 붙인다.

같은 요약 API에서 공통 집계를 쓰는 주도권·1:1·솔로 비중 시각화와 추세에도 누락값 제외가 적용된다. 저장된 경기 수치·티어 산식·텔레메트리 원본은 변경하지 않는다.

## 기존 보호 장치 점검

- 서로 다른 FPP/TPP 또는 매치 유형이 섞인 카드에는 더 좁은 조건의 평균을 붙이지 않는다.
- 지표별 비교 표본이 부족하거나 비교값이 NULL이면 우열 비교에 사용하지 않는다.
- 주제 ID가 제목·질문·허용 지표를 결정하며, 다른 카드의 근거 참조와 확인된 교차 주제 문구를 거절한다.
- 이 검사는 모든 자연어 의미 불일치를 이해하는 범용 의미 검증은 아니다.
- 새 경기 수 필드는 캐시·브라우저 파싱에도 보존한다. 음수·소수·선택 경기보다 큰 값 및 0경기인데 관측값이 있는 저장 카드는 거절한다. 옛 카드에 필드가 없으면 지표별 확인 경기 수 미확인으로 표시한다.
- 최근 요약 캐시 버전은 `2026-09-08.debate-observed-coverage-v17`이다. 운영 캐시 일괄 삭제는 하지 않았다.
