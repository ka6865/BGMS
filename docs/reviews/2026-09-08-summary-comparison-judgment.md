# 최근 최대 10경기 토론: 비교 방향과 일관성 추론 보강

## 이번 변경

범위는 최근 최대 10경기 AI 토론이다. 평균값·합계만으로 경기별 일관성을 단정하는 실제 응답과, 비교 가능한 지표가 모두 유리한데 일반적인 연습 제안만으로 ‘장단점 함께’가 되는 사례를 보강했다.

- ‘꾸준히 높은 피해량을 기록한 점’, ‘꾸준한 딜링 능력을 증명’ 등 확인된 과거 실적 단정을 제거한다. ‘다음 경기에서도 꾸준히 기록해 보세요’ 같은 미래 조언과 평균 수치 자체는 유지한다. 경기별 분포를 새로 계산하거나 꾸준함을 점수화한 것은 아니다.
- 기존 지표별 비교 방향 표를 공통으로 사용한다. 피해량·복수 성공률 등은 높을수록, 백업 시간 등은 짧을수록 유리한 방향으로 판정한다. 이 정책을 새로 정의하거나 계산식을 바꾸지 않았다.
- `draw`인데 카드의 비교 가능한 지표가 모두 엄격히 유리한 방향이면 `null`로 바꾼다. 의견과 증거는 유지하며 평가를 해당 비교 근거의 범위로 정리한다. 최종 문장도 다시 구성하여 거절된 혼합 판정을 그대로 반복하지 않게 한다.
- 평균과 같은 값, 비교 방향이 정의되지 않은 지표, 유리·불리한 지표가 실제로 함께 있는 경우에는 이 규칙으로 판정을 바꾸지 않는다. 모든 불리한 지표/동률/미측정에 대한 혼합 판정 전체를 검증하는 일반 판정 엔진은 아니다.
- 매운맛 코치도 긍정적인 평가를 할 수 있으므로 `spicy` 자체를 부정 평가로 취급하지 않는다. `kind` 승리로 강제 전환하지도 않는다.
- 생성 응답, 캐시 재구성, 클라이언트 카드 검증에 연결했다. 최근 요약 캐시 버전은 `2026-09-08.debate-comparison-judgment-v15`다.

## 검증

새 회귀 사례는 변경 전 4개 실패를 확인한 뒤 수정했다. 복수 성공률/백업 시간이 모두 유리한 경우의 보류, 성공률과 시간의 실제 장단점이 섞인 경우의 유지, 동률 유지, 변조된 저장 카드 거절, 원문 조언·증거 보존을 검사했다. API 캐시 재조회에서도 동일한 판정이 유지된다.
