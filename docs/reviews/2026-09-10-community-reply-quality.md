# 커뮤니티 답글 품질 개선 검증

공식 패치노트를 읽지 못한 채 안내 문구만 생성하던 문제를 수정했다. 게시글의 공식 링크 또는 제목의 패치 버전으로 원문을 조회하고 자체 제목에서 버전을 검증한 뒤 모델에 전달한다. 일정 질문의 원문 조회 실패와 회피성 안내는 보류하고 정상 초안에는 출처를 붙인다.

## 실제 생성 결과

- 질문: 업데이트가 언제야?
- 게시글 맥락: 배틀그라운드 43.1 패치, 주술회전 콜라보와 신규 액션 업데이트 소식
- 조회: 공식 목록 → https://pubg.com/ko/news/11057
- 모델: gemini-3.5-flash-lite
- DB RPC는 메모리 테스트 더블을 사용했다. 실제 Gemini·공식 사이트 요청만 수행했고 공개 댓글 작성/Discord 전송/DB 수정은 하지 않았다.

> 배틀그라운드 43.1 패치 업데이트는 한국 시간 기준으로 PC 버전은 2026년 9월 10일 09:00부터 17:30까지, 콘솔 버전은 2026년 9월 17일 10:00부터 18:00까지 진행될 예정입니다. 단, 명시된 점검 시간은 점검 상황에 따라 변경될 수 있으니 참고하시기 바랍니다.
>
> 출처: https://pubg.com/ko/news/11057

## 검증

- `npm run verify:community`: 17개 파일, 179개 테스트 통과.
- `npx tsc --noEmit --pretty false`: 통과.
- 변경한 답글 모듈/원문 조회 모듈/테스트 ESLint: 통과.
- `git diff --check`: 통과.
- 원문 조회 제한: 총 10초, 리다이렉트 포함 최대 3회, 응답당 2MiB, 모델 본문 12,000자. 허용하지 않은 호스트/인증정보 포함 URL/댓글 URL은 조회하지 않는다.

## 적용 범위

develop 작업트리에 반영했으며 커밋·운영 배포는 하지 않았다. 168번 게시글과 67번 댓글은 삭제된 상태여서 해당 검토 항목을 덮어쓰거나 재게시하지 않았다. 다음 새 답글 생성부터 이 로직을 사용한다. 공식 한국어 패치노트에 대한 조회이며 일반 웹 검색을 구현한 것은 아니다. 기존 Discord 채널 권한/운영 배포/예약 활성화 연결은 별도 미완료 상태다.
