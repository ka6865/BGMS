# 최근 최대 10경기 AI 토론 실데이터 평가

## 평가 범위와 사전 기준

현재 develop 서비스 라우트의 프롬프트·경기 선정·후처리를 사용한다. 테스트용 별도 프롬프트로 정확도를 측정하지 않는다. 운영 DB는 steam의 KangHeeSung_와 MiaeQ_Q에 한정해 경기 시작 시각 내림차순으로 각각 25개 결과를 조회한 스냅샷을 사용한다. 비교 자료도 같은 시점의 계산 버전 2/모집단 근거 버전 1 자료를 동결한다. 실제 Gemini만 외부 호출하며 인증·DB·캐시·사용량 기록은 메모리로 격리한다.

| 검사 | 허용 | 금지 |
| --- | --- | --- |
| 경기 범위 | 실제 선정된 최근 최대 10경기와 카드별 근거 경기 수 구분 | 일부 경기의 관측을 10경기 전체의 기록으로 확대 |
| 비교 | 해당 카드와 같은 조건의 비교 평균에 대한 높고 낮음 | 비교 자료가 없는데 상위권/평균 이상·미달 확정 |
| 화력 | 관측된 피해량과 평균의 관계 | 높은 피해량만으로 선공·교전 주도·팀원 지원 부족 단정 |
| 유틸리티 | 투척 사용량과 기록된 구출 기회/성공 | 보유량·남긴 아이템 추측, 기회 없음/미측정을 실패 0%로 해석 |
| 백업 | 시간과 실제 복구 결과 분리, 조건부 연습 행동 | 시간 하나로 구조 성공/실패·방관·소통 상태 추측 |
| 포지셔닝·생존 | 관측된 거리·고립·사망 시점의 한계 설명 | 시야·엄폐·판단 의도·사망 원인을 단정 |
| 결론 | 장단점 모두 근거가 있으면 혼합, 불충분하면 보류 | 승자나 약점을 억지로 만들거나 보류 카드를 최종 문장에서 확정 비판 |

서버의 구조 검증 통과와 의미 검토 통과를 별도로 기록한다. 원본 응답과 정제된 화면 응답을 함께 읽어, 오류를 가린 정도와 생성 자체의 품질을 구분한다. 소수 사례를 전체 정확도로 환산하지 않는다.

## 재실행

`tests/ai-summary-quality-real.integration.test.ts`는 기본 테스트에서는 실행하지 않는다. 동결 자료를 준비한 뒤 `RUN_AI_SUMMARY_QUALITY_REAL=true AI_SUMMARY_QUALITY_FIXTURE=<local-json> AI_SUMMARY_QUALITY_OUTPUT=<output-dir> npx vitest run tests/ai-summary-quality-real.integration.test.ts`로 두 유저를 순서대로 평가한다. 모델 호출은 실행당 최대 6회이며, 운영 DB 통신은 평가 단계에서 차단한다.

실제 원본 텔레메트리를 이용한 별도 소수 경기 검사는 기존 `tests/telemetry-gemini-real.integration.test.ts`의 summary 사례를 사용한다. 이 사례는 2경기 입력이므로 ‘10경기 모두 원본 재계산 검증’으로 표현하지 않는다.

## 실제 호출 결과와 수정

이번 평가의 실제 Gemini 호출은 총 **7회**, 모델은 모두 `gemini-3.5-flash-lite`였다. 입력 23,491토큰/출력 4,363토큰이며 과거 배포 검증 호출과는 별도다. 모델 학습이나 모델 교체를 한 결과는 아니다.

| 단계 | 실제 호출 | 결과 |
| --- | ---: | --- |
| 변경 전 기준선 | 두 유저 각 1회 | 구조 검증 2/2 통과. 집중력·기동력·주도권 단정 등 의미 문제는 별도로 발견 |
| 1차 보강 | 두 유저 각 1회 | 1/2 통과. MiaeQ_Q의 복합 비교 문장이 기존 엄격 정제기에서 제거되어 한 카드 해석 거절 |
| 비교 문장·측정 정의 보강 | 두 유저 각 1회 | 구조 검증 2/2 통과. 원본에 집중력·보유량·사용 빈도에 대한 추론이 남아 후처리를 추가 보강 |
| 원본 텔레메트리 2경기 | MiaeQ_Q 요약 1회 | 원본→필터링→캐시 투영 재계산의 동일성 및 실제 요약 라우트 통과. 비교 자료 없이 승자 보류 |

### 최근 10경기 요약: 두 유저

두 유저 모두 25개 저장 결과에서 최근 유효 10경기, 점수 기준 최대 5경기가 선정됐다. 토론의 직접 비교 근거는 **듀오 경쟁전 4경기**였다. 두 유저의 비교 자료는 B 티어·듀오·경쟁전 조건이며 전체 비교 표본 49건, 복수 성공률/연막 구출률 28건, 백업 시간 7건 등 지표마다 표본 수가 달랐다.

- KangHeeSung_: 평균 화력 403 대 199, 복수 성공률 33% 대 17.3%, 백업 시간 10.97초 대 15.57초, 1:1 승률 73% 대 58.9%, 솔로 킬 비중 80% 대 73.8%.
- MiaeQ_Q: 평균 화력 228 대 199, 복수 성공률 33% 대 17.3%, 백업 시간 5.36초 대 15.57초. 투척 총 17회, 연막 8회, 피해형 투척 8회, 구출 연막 시도 1회. 아군 기절 대비 연막 구출률 0/3=0% 대 10.1%.
- 여기의 0%는 기회가 실제로 관측된 0/3이며 미측정을 0으로 바꾼 값이 아니다. 사용 횟수에는 같은 조건의 비교 자료가 없으므로 적정 사용 빈도나 보유량 대비 활용도를 판단할 수 없다.

### 원본 2경기를 사용한 요약: MiaeQ_Q

기존에 보관한 실제 스쿼드 경쟁전 원본 2경기를 재계산했다. 이 실행의 기능은 **최근 최대 10경기 요약 API에 2경기를 입력한 검사**이며 스쿼드 시너지 분석 API 검사가 아니다.

- 개인 투척 4회, 연막 3회, 피해형 투척 1회, 구출 연막 시도 1회, 아군 기절 대비 연막 구출 0/4=0%, 평균 고립 지수 0.7, 평균 사망 페이즈 5.5.
- 비교 평균을 주입하지 않았으므로 세 카드 모두 `user_only`이며 승자는 `null`이다.
- 모델이 비교 기준 없이 “고립 지수가 기준에 부합”이라고 쓴 문장도 발견해 알려진 추론 검사에 추가했다.

### 반영한 동작

1. 요약 프롬프트에서 개인 백업 시간의 실제 의미를 명시했다. `CombatHandler`는 아군을 기절시킨 적을 30초 안에 처치한 성공 사례의 경과 시간을 기록하고, 엔진은 그 시간의 평균을 계산한다. 요약은 관측된 경기별 시간을 집계한다. 이동 속도·첫 대응 시간·전체 구조 기회 평균으로 설명하지 않는다. 스쿼드 분석 시간 정의와 구분한다.
2. 한 문장에 지표 하나와 방향 하나를 쓰도록 지시했다. 두 지표가 모두 유리한데 일반적인 연습 제안만으로 혼합 판정을 만들지 않도록 했다.
3. `aiSummaryJudgment.ts`에 실제 발견한 미측정 추론의 제한 규칙을 추가했다. 정상 사실 문장과 조건부 조언은 남기고, 불가피하게 전부 제거될 때만 해당 해석을 보류한다. 제거로 판단 근거가 달라진 카드의 승자는 `null`로 바꾼다.
4. 카드·최종 문장·칭호 설명·행동 제안에 같은 정리를 적용한다. 저장된 카드가 검사를 우회하지 않도록 읽기 검증에도 연결했다. 수치·근거 ID·모드·표본은 수정하지 않는다.
5. 최근 요약 캐시 버전은 `2026-09-08.debate-evidence-meaning-v14`로 갱신했다. 운영 캐시 삭제·일괄 생성은 하지 않았다.

최종 실제 응답을 최신 코드로 오프라인 재생한 API 검사 2/2가 통과했다. 캡처된 프롬프트와 시스템 지시가 현재 라우트와 일치하는지도 검증했다. 추가 Gemini 호출은 없었다. KangHeeSung_는 카드 3개 모두 해석 유지, MiaeQ_Q는 카드 3개 모두 해석·수치 유지하되 백업과 유틸리티의 승자만 보류했다. 원본 2경기 사례도 세 카드의 수치와 보류 상태가 유지됐다.

## 해석과 남은 한계

7개 원본 응답을 최신 공통 정규화기로 재생했을 때 이번에 규칙화한 미측정 추론은 최종 결과에서 검출되지 않았다. 이 수치는 전체 의미 오류가 0이라는 뜻이 아니다. 초기 원본 응답 중 일부는 정상 의견이 남지 않아 카드 해석이 보류됐으며, 그 실패도 기록했다.

평균값을 ‘꾸준한 습관’으로 확대하는 일반화, 조언의 구체성, 혼합 판정이 실제 장단점을 반영하는지 등은 더 넓은 독립 사례로 평가해야 한다. 표현 규칙을 끝없이 늘리는 대신, 후속 평가에서는 경기별 분포·비교 방향·분모에 대한 정답 항목을 추가하는 것이 우선이다. 같은 두 유저의 동일 경기로 반복 조정한 결과이므로 별도 평가 자료에서 재검증하기 전 일반적인 정확도 향상률을 발표하지 않는다.

로컬 상세 자료: `tmp/summary-quality-eval/{baseline,after,final,final-replay,raw-two-match}`, 전체 재생 비교 `tmp/summary-quality-eval/replay-audit.json`. 해당 파일은 개인정보와 원본 모델 응답을 포함하는 로컬 감사 자료이며 Git에 포함하지 않는다.
