# 전날 우승 경기 분석 운영

`/learn/daily`는 매일 KST 기준 전날의 스팀 경쟁전 우승 경기 한 건을 보여준다. 날짜당 한 건은 `daily_ranker_stories.day_kst` 기본 키로 보장한다.

GitHub Actions의 `daily-ranker-story.yml`이 매일 09:37와 12:37 KST에 실행된다. 두 번째 실행은 첫 번째가 실패했을 때의 재시도이며, 이미 발행된 날짜는 건너뛴다. 수동 재실행은 Actions의 `day_kst` 입력 또는 로컬에서 `npx tsx scripts/publish_daily_ranker_story.ts --apply --day=YYYY-MM-DD`로 한다. `--apply`를 빼면 DB에 쓰지 않고 미리보기를 출력한다. 필요한 비밀값은 `PUBG_API_KEY`, `GOOGLE_GEMINI_API_KEY`, `NEXT_PUBLIC_SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`다.

선별은 현재 시즌 AS 리더보드에서 솔로와 스쿼드를 날짜에 따라 번갈아 먼저 살핀다. 모드별 상위 20명의 최근 최대 14경기를 조회하고, 스팀 경쟁전·해당 모드·요청한 KST 경기일·같은 계정의 1위를 확인한다. 텔레메트리의 매치 식별자와 API 킬 수가 일치해야 발행한다. 한 후보의 텔레메트리가 없거나 검증에 실패하면 다음 우승 후보를 살핀다. 검증된 후보가 없거나 AI 요청이 실패하면 발행하지 않고 작업을 실패 처리한다.

킬 귀속 무기는 `LogPlayerKillV2.killerDamageInfo`를 우선한다. 스쿼드에서는 팀원이 다른 무기로 기절 상태를 마무리해도 원래 킬 귀속자의 무기를 표시한다. AI는 확인된 이벤트 ID 중 핵심 사건 2~5묶음을 고른다. 공개 문장과 시간은 선택된 원본 이벤트로 다시 조립하므로 모델이 쓴 위치·의도·인과 추정은 게시되지 않는다. 페이지에는 경기 요약, 사건 흐름, 개인 무기, 자기장 관측과 알 수 없는 점을 표시한다.

초기 실경기 검증: 2026-09-23 스쿼드 미라마, 매치 `372fc5fd-7b71-46cf-a891-192691e5f474`, 개인 3킬·팀 15킬, 귀속 무기 M416 2킬·Mk12 1킬. 이 날짜의 글은 DB에 발행했다. 이후 글은 워크플로가 기본 브랜치에 반영되어야 자동 발행된다.
