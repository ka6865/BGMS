# 검토된 추천 조합 적용과 비활성·삭제 조회

사용자 요청: 개발자가 최초 이름 연결을 직접 마치고 실제 자료를 적용한다. 비활성·삭제 항목도 보관하고 필터로 조회할 수 있게 한다.

- 운영 원본 #5의 이름 249개를 공식 16.21 KIWI 카탈로그/원본 페이지와 대조했다. 현재 사용 206개, 공식 비활성 4개, 원본 삭제 기록 39개다. 이름이 비슷하다는 이유로 연결하지 않는다. Double Defense/Bolstered, 퀘스트 접두어, 등급 차이 2개는 설명으로 확인한 검토 근거를 기록한다. Void Immolation은 같은 한국어 이름의 현행 증강과 임의 연결하지 않고 원본 삭제 기록으로 보존한다.
- 최초 사용 가능한 206개 연결은 기존 관리자 map API로 저장한다. 이전 값 보관, 관리자 확인/감사 기록을 유지한다. 운영 DB 스키마 변경과 원본 삭제는 없다.
- 정규화 v2: 원본 전체와 검토 파일을 보존하고 현재 사용 조합/선택률만 DB 추천 자료로 적재한다. 비활성·삭제·확인 중은 별도 archive에 보존한다. metadata에 원본/추천 개수·상태별 개수·archive 해시를 기록한다. 검증 대상의 unknown_count와 보존 항목을 혼동하지 않는다. 원본이나 공식 이름이 바뀌면 확인 중으로 분리한다.
- 전체 공식 증강 중 내부 전용 항목을 제외한 현재 사용/비활성 항목과 원본 삭제 항목을 보존 목록에 포함한다. 비활성은 공식 상태, 삭제는 확인한 원본 삭제 패치/링크를 표시한다. 단순 미등장·조회 실패는 삭제가 아니다.
- 공개 조회는 기존 승인·공개 게이트를 그대로 거친 저장본에서만 읽는다. 보존 JSON 해시·경로·용량·타입을 검증한다. 자료를 펼쳤을 때만 새 조회를 시작하고 50개씩 보여준다. 증강/조합, 현재 사용/비활성/삭제/확인 중/전체, 검색·챔피언 필터를 제공한다.
- 자동수집도 같은 정규화를 사용한다. 원본 통계와 보존 자료를 섞지 않고, 새 후보 저장과 공개는 구분한다.

검증: 이름/효과 대조 근거와 예외, 공식 비활성 및 원본 삭제 우선순위, 모르는 항목의 확인 중 처리, 잘못된 연결·중복 ID·해시·부족한 카탈로그 차단, 승인 전 원본 접근 차단, 필터/검색/응답 경합/빈·오류 상태. core/LoL/admin와 모바일 375×667·390×844·430×932·데스크톱 브라우저 확인 후 PR·머지·배포 및 실제 운영 적용/공개 검증.
