# 증바람 조합 이름 연결과 세부 화면 정리

기존 기본 화면 개편만으로는 조합 ID 매핑 입력과 세부 탭이 그대로 남아 있었다. 일반 관리자 화면은 수집·적용 요약과 한글 이름 연결만 남긴다. 사용처가 없어진 기존 참조 자료/챔피언 검토 컴포넌트와 전용 화면 테스트는 제거한다. 승인·공개 경계는 새 요약 화면과 기존 API 테스트로 검증한다. 검수·복구 API는 변경하지 않는다.

- 저장된 원본의 증강/조합 이름을 읽는 관리자 전용 미리보기를 기존 API에 추가한다. 이름·등급과 같은 패치 공식 카탈로그 설명을 제공하고 외부 ID는 기본 화면에서 숨긴다. 외부 파일/행 수와 문자열을 검증하며 클라이언트에 원본 경로·키를 전달하지 않는다.
- 이름이 정확히 일치하는 단일 공식 증강만 연결 후보로 제시한다. 동명이인·다른 등급은 자동으로 고르지 않는다. 연결은 관리자 확인과 기존 map API의 감사 기록을 거친다.
- 한국어 이름으로 검색·비교·선택하고 저장 완료를 안내한다. 일치 후보 일괄 연결도 대상 이름 목록과 명시적 확인이 필요하다. 오류/패치 전환/화면 이탈 시 다음 요청을 멈춘다.
- 연결 저장은 공개하지 않는다. 연결 결과 반영으로 재수집한 비공개 후보는 요약 화면에서 별도로 확인·적용한다. API 키를 추가로 쓰는 ARAMGG 조회는 없다.

검증: 원본 이름 파싱/충돌/누락/한도, 한글·영문 정확 일치와 동명·등급 충돌, 인증/입력 경계, 확인 전 쓰기 차단·일괄 중단·패치 전환·저장 후 상태를 테스트한다. 기존 모바일 3종과 데스크톱 fixture를 새 화면 기준으로 바꾸고 core/LoL/admin 및 PR CI 통과 후 머지·배포한다. 운영 DB 스키마와 기존 매핑 값은 변경하지 않는다.
