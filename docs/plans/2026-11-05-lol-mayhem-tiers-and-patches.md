# 증바람 챔피언 티어와 패치별 증강 순위

사용자 요청: 챔피언 목록에 공급원 티어와 티어순 정렬, 확보 가능한 과거 패치 증강 순위를 필터로 제공한다. 배포/머지는 하지 않는다.

1. 이미 인증 조회한 ARAMGG26.21.5의173명 챔피언 ID·티어(1~5)만 정규화한 작은 버전 고정 JSON을 저장한다. 이름·초상화는 기존 공식 자료를 쓴다. 최신 패치인 것처럼 바꾸거나 자체티어를 계산하지 않는다. 패치 불일치/없는 티어는 미제공, 동일티어는 기존이름순, 미제공은마지막. 첫화면에키/유료조회추가없음.
2. arammayhem.com의 공개CC BY4.0 인덱스와패치별augments.json을연결한다. URL은26.xx의검증된목록에서만생성, 응답크기/비율/ID/패치/날짜검증, 서버6시간캐시. 원본지역이구분안되는전체선택률이며챔피언별로가공하지않는다. 출처링크필수유지.
3. `패치별 증강 순위` 보기에서패치/등급/검색을제공한다. 실제선택률내림차순, null은끝,0과구분, 한행에하나. 과거이름/등급은과거스냅샷값사용(현재도감강제덮어쓰기없음). 챔피언선택과무관한전체순위임을명시.
4. 기존공개flag/readguard API로읽고원본미확인자료는연동안함. 티어파서/정렬/파일모드/과거패치파서/API경계/브라우저4뷰포트/실제로컬에서확인. 계획이력과확보하지못한챔피언별과거기록한계를보고한다.
