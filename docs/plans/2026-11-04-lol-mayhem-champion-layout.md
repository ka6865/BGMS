# 증바람 챔피언 선택 화면 개선

사용자가 제시한 화면처럼 데스크톱은 왼쪽 초상화·검색·스크롤 챔피언 목록과 오른쪽 챔피언 헤더·증강 카드로 구성한다. BGMS의 어두운 배경과 노란 강조색을 유지한다. 모바일 챔피언 목록은 접을 수 있게 해 증강을 먼저 읽는다.

- 기존 Data Dragon 버전을 페이지 → View → 통계 컴포넌트로 전달해 초상화를 표시한다.
- 검색은 목록만 필터링하고 실제 선택은 버튼으로 확정한다. 검색 중 빈 결과가 나와도 기존 챔피언 통계를 유지한다.
- 선택률 정렬·검색·등급·오류/재시도·이전 응답 차단은 유지한다.
- 증강을 1/2/3열 카드로 표시하며 등급·아이콘·효과·선택률을 강조한다. 출처·지역 문구는 사용자 요청에 따라 화면에서 제거하되 저장된 데이터와 검증은 유지한다.
- 기존 fixture 브라우저 하네스의 375×667, 390×844, 430×932, 1440×900과 실제 수집본 로컬 화면을 검증한다. 새 API·DB·의존성을 추가하지 않는다.

## 추가 요청: 증바람 전용 아이템 자료 (배포 금지)

사용자가 증바람 전용 자료만 요청했다. 일반 칼바람450 템트리·스킬·주문 연동은 제외한다. IESDEV의 공개 `aram_mayhem_champion?champion_id`에서 챔피언별 증바람 아이템 평가 등급을 확인했다. 현재자료는16.22이며 선택률·구매순서·스킬·주문은 제공되지 않는다.

- `LOL_MAYHEM_ITEMS_ENABLED`를 로컬에만 켠다. 새 자료는 서버에서6시간 캐시한다. API 키를 쓰지 않는다.
- 응답의 query/game/champion_id/patch/date/tier와 크기를 검증하고 Riot Data Dragon의 같은 패치 이름·아이콘·제작 재료를 연결한다.
- 증강16.21과 아이템16.22의 패치·기준일을 각각 표시한다. 추천 등급을 선택률·실측 구매 순서로 변환하지 않는다.
- 챔피언 전환과 오래된 응답 차단, 검색·등급필터, 모바일 뷰포트, 오류/빈값을 검증한다. PR #434는 draft로 유지하며 머지·배포하지 않는다.
