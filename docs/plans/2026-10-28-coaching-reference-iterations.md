이 배치는 상위5경기 칭호 검증을 새로 주장하는 자료가 아니다. 첫 확인에서 통과한 역할 검증은 그대로 두고, 추가 benchmark 관측만 분리 집계한다. 첫 확인+추가 관측의 반격 평균·계정 cluster 신뢰구간과 추가 관측만의 결과를 모두 보고한다. 추가만으로도 n30·계정20을 요구하며, 합친 확인의 반폭0.15초를 확인한다. 이미 본 첫 확인을 ‘한 번도 보지 않은 새 검증’이라고 표현하지 않는다. 후보·지표 정의·통과 문턱은 바꾸지 않는다. seed는 기존 값을 유지하고 추가 전용 집계의 suffix만 `benchmark-supplement-1`로 고정한다.

600계정 모두의 경기 metadata를 확인했다. 후보 선정 시각은2026-10-28 18:04:31 KST, 계정 manifest SHA256은 `a01c0ffa878e5e13b5250f5bbc507db93f1701e9d3b2928841dd099364196a11`이다. 최근 유효 창·조건·기존 경기 제외·경기별 hash 선정을 거친 실제 계산 대상은3,567개 개인 전적(듀오 경쟁851·스쿼드 일반2,716)이다. 입력 manifest SHA256은 `72049ae7417cbaa79ca4afe4be13e474b795bda58ef2d83ea3eaa09cc0d031ec`이며 새 수치를 보기 전 고정했다.

`validate_coaching_expansion.ts --benchmark-supplement`는 이 추가 자료의 계정/경기 중복·버전·identity를 확인하고 benchmark를 별도로 집계한다. 추가 자료로 역할 프로필을 만들거나 원래 후보를 fitting하지 않는 회귀 검증을 추가했다. 공통 수치 함수는 유지한다.

## 보완 확인 결과

고정한3,567개 중3,565개를 계산했고 스쿼드 일반의2경기는64MB 상한 초과로 각3회 시도 후 제외했다. 듀오 B군의 새 적격 관측은42전적·38계정, 스쿼드 일반 A군은87전적·68계정이다. 추가 자료 단독의 n30·계정20 조건을 충족한 뒤 값을 확인했다.

첫 확인과 합친 반격 구간 반폭은 듀오 경쟁0.12890초(150전적·138계정), 스쿼드 경쟁0.13235초(93·86, 원래 확인 유지), 스쿼드 일반0.11497초(169·139)로 세 조건 모두0.15초 목표를 충족했다. 추가 단독 듀오 반폭은0.19395초로 아직 넓으며, 이를 별도의 정밀도 통과로 주장하지 않는다. 후보와 통과 문턱은 그대로다. KangHeeSung_의72% 칭호 전환 보류와 희소 조건 보류도 유지한다.

공개 CLI의 보완 입력 재생에서 원래 첫 확인과 candidate는 deep equality가 일치했고, 추가/합산 precision과 추가 coverage도 별도 검증과 일치했다. 현재 registry와 전체3,322계정의 중복은0이다. 최종 코드 `66983031`을 Node24.22.1에서 공통0오류·기존49경고, 전체단위5,605통과/219skip, 분석702통과/6skip, 집중37통과로 확인했다. 정적 재검토에서도 P1/P2 지적은 없었다.
