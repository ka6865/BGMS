# 벤치마크·칭호 기준 2차 재산출 설계

사용자가 승인한 2차 범위를 로컬 재계산·후보 검증까지 실행한다. 1차 PR #378의 efd61d20을 기반으로 독립 하위 워크트리에서 작업한다. 운영 migration·DB/R2 쓰기·배포·기준 활성화는 이번 실행에 포함하지 않는다.

- Steam 스쿼드 우선, 일반/경쟁·TPP/FPP를 구분한다. 실제 확인 결과 지정 두 계정의 최근 상위5경기는 듀오 경쟁이므로 듀오를 별도 검증 cohort로 포함한다. 스쿼드 표본을 듀오 기준에 섞지 않는다. 최근 저장 전적 20,000행의 552계정 후보 프레임에서 계정 단위 seeded 순서로 최대400개와 지정 두 계정을 평가한다. 프레임 상한·원본 누락·검색 표본 편향을 보고한다.
- 화면의 최근 유효 최대10경기→점수 상위5경기 선택과 집계 함수를 그대로 재사용한다. 함수 본문을 복제하거나 VM으로 추출하지 않고 순수 공통 모듈로 옮긴다. 현재 계산5·결과73과 신원/원본 checksum을 검증한다.
- 원본으로 재계산하거나 현재 계산5 canonical의 검증된 관측을 사용한다. 최신 경기 창에서 점수를 모르는 경기 때문에 상위5 선택을 확정할 수 없으면 해당 프로필은 분포 학습에서 제외한다. 누락을 임의로 더 오래된 경기나 0으로 대체하지 않는다.
- 한 계정은 역할 분포에 한 번만 기여한다. 계정 hash로 80/20 학습·holdout을 나누며 지정 두 계정은 항상 별도 검증 대상이다. 혼합 모드/유형 프로필은 별도 집계하고 단일 조건의 분포에 섞지 않는다.
- 개인 benchmark는 동일 raw mode·match type·tier의 player-match 평균이다. 지표별 유효30건 미만은 비교 보류한다. 정확한 티어와 기존 reader가 허용하는 동일 티어군 fallback을 별도로 산출하며 모드·유형을 넘겨 섞지 않는다. 계정당 경기 창 상한을 두고 계정 수/집중도를 같이 제시한다.
- 역할은 적격 반격 소요 시간을 입력으로 사용해 지표별 CDF와 복합 역할 CDF를 함께 산출한다. 기존 결측·팀 역할·pointMan 필수 조건을 공유한다. 각 지표/역할은 학습50계정·holdout20계정 이상을 후보 검증의 최소 가드로 삼는다. 이는 충분한 정확도 보증이 아니라 작업자가 정한 소표본 보호다.
- 후보는 관측 범위·결측률·holdout 분포·계정 단위 bootstrap 민감도를 보고한다. 역할 비율을 맞추는 임계값 튜닝은 하지 않는다. 현재 운영 분포 버전1과 계산 점수는 유지한다.
- 기존 classifier에 선택적 reference 인자만 추가해 같은 역할 로직으로 구/신 후보를 비교한다. 후보에 없는 지표·역할은 null이며 기존 분포로 fallback하지 않는다. 운영 기본 호출은 기존 분포를 그대로 사용한다.
- 공개 결과물에는 익명 계정 집계, 두 지정 계정의 칭호 이동, 표본 커버리지와 기준 후보를 제공한다. 계정 목록·원본·credential은 Git에 넣지 않는다. CLI는 운영 select/GET만 허용하고 재실행 가능한 로컬 결과를 만든다.

접근 선택: 전체 분포를 즉시 운영 교체하는 방법은 표본·누락 편향을 검증하기 전이므로 채택하지 않는다. 재현 가능한 후보 산출과 별도 holdout 검증을 먼저 수행한다.
