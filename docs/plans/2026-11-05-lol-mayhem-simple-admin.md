# 증바람 관리자 화면 단순화

사용자가 요청한 수집 내용 → 적용 시 바뀌는 내용 → 적용 완료 흐름을 기본 화면으로 만든다. 기존 관리자의 자료 선택·검수·공개 용어와 기술 정보를 기본 화면에서 제거한다.

- `MayhemDatasetReviewPanel.tsx`: 기본 화면을 새 수집/적용 목록으로 교체한다. 기존 관리 도구는 `이전 자료·문제 해결`을 열 때만 표시한다.
- `LolMayhemUpdateSummary.tsx`: 기존 관리자 GET 3개를 읽어 챔피언 증강, 챔피언 티어, 아이템 평가, 과거 증강 순위, 증강 조합을 한글로 요약한다. 자료별 수집일·적용일과 적용하면 달라질 화면을 보여준다.
- 적용할 최신 자료는 실제 사용자 선택 규칙을 따른다. 같은 대상의 중복 수집본은 제외하고 아이템은 챔피언별 가장 최근 패치를 우선한다. 적용 대상·현재 자료·새 자료를 확인한 명시적 클릭만 승인 후 공개 API를 순서대로 호출한다. 인증, 확인, 충돌 검사, 검증, 감사 기록은 기존 API를 그대로 사용한다.
- 오류 시 첫 실패에서 중단하고 이미 적용된 수와 재확인 방법을 안내한다. 적용 중 대상은 바꾸지 않으며 화면을 벗어나면 다음 쓰기를 멈춘다. 새로고침 실패를 적용 실패로 잘못 보고하지 않는다.
- 누락 파일, 이름 미연결, 비활성 설정은 이유를 한글로 표시하고 적용을 막는다. 자동수집은 계속 비공개 자료만 저장한다.

검증: 최신 자료 선택/과거 자료 제외, 확인 전 쓰기 없음, 승인→공개, 충돌 중단, 부분 적용과 재조회 실패, 비활성/미연결 차단을 테스트한다. 기존 브라우저 fixture를 재사용해 모바일 375×667·390×844·430×932 및 데스크톱에서 기본 화면·확인·완료·고급 도구와 가로 넘침을 확인한다. `verify:core`, LoL·관리자 테스트와 PR CI 통과 후 main 병합 및 운영 배포한다. DB 변경은 없다.
