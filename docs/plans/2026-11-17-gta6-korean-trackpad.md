# GTA6 한국어 표시와 트랙패드 개선

사용자가 한글화 방법·입력 지연 원인 설명 후 구현을 승인했다. 기존 Leaflet과 정적 데이터 구조를 유지한다. `.agents/rules/project_rules.md`는 이 워크트리에 없어 AGENTS.md·실제 구현을 기준으로 한다.

- [x] 한국어 사전을 분리·확장하고 `originalName`, `displayAddress`를 제공한다. 원본 JSON·ID·저장 계약은 보존하며 미확인 이름은 만들지 않는다. 한영 검색과 추정 기호 보존을 단위 검사한다.
- [x] 상세/목록에 한국어 주소·영문 원문을 표시하고 주요 6개 지역의 한국어 지명을 지도 위에 겹쳐 표시한다. 번역은 비공식 표기임을 안내한다.
- [x] Leaflet 기본 휠 누적 처리를 유지하되 확대 애니메이션의 입력 차단과 단계 스냅을 제거한다. 입력 배치 간격은 16ms, 감도는 20px로 조정한다. 기존 60px에서는 Mac 정규화 후 작은 입력 10개가 줌 약 0.08에 그쳐 원본 3배 보정을 상쇄하도록 낮췄다. 별도 입력 라이브러리를 추가하지 않는다.
- [x] 화면 주변의 마커만 렌더링하고 각 마커를 memo 처리해 위치·스타일이 같으면 다시 설정하지 않는다. 선택 장소는 항상 표시한다.
- [x] 모의 연속 휠·Ctrl 휠, 버튼·공유 선택·방문 저장, 375x667·390x844·430x932·데스크톱, 경계 크롭을 검증한다. `verify:core` 및 GTA6 관련 단위 검사를 실행한다.

실제 맥북 트랙패드/Safari의 제스처 감각은 자동화된 Chrome 입력과 구분해 보고한다. 운영 배포·새 데이터 수집·계정 동기화는 범위 밖이다.

검증 결과: Node 24에서 `npm run verify:core` 통과(기존 경고 43건, 오류 0건). GTA6 데이터·UI·홈·독립 경로 검사 4개 파일 38개 통과. 격리 Chrome의 4개 뷰포트 및 일반/Ctrl 휠·저장·원문 표시·크롭 검사 통과. 독립 코드 리뷰에서 Critical/Important 없음. 전체 단위 검사 재실행과 실기기/Safari 검증은 범위 밖으로 남겼다.
