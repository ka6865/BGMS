# 증바람 챔피언별 선택 관측 이력

사용자가 승인한 표시 규칙을 기존 증바람 챔피언 화면의 별도 `관측 이력` 보기에 추가한다. 배포와 머지는 하지 않고 PR #434 초안을 갱신한다.

- 현재 기준 패치와 같은 시즌의 앞선 3패치, 최대 4패치만 비교한다. 공개 게시된 검증 스냅샷과 해당 패치의 공식 카탈로그만 사용한다. 새 DB·원본 수집·쓰기·외부 유료 호출은 추가하지 않는다.
- 현재 선택 관측, 과거 관측 뒤 연속 미관측, 조회 범위 내 관측 이력 없음, 자료 부족을 구분한다. 양의 선택률 또는 같은 모집단의 검증된 선택 표본만 관측 근거다.
- 현재 스냅샷의 선택률 소스·지역을 기준으로 비교한다. 다른 소스·지역, null 지표, 게시본 없음, 수집/검증 실패, 증강 미존재 패치는 자료 부족이다. 중간 자료 부족을 건너뛰어 연속 미관측 시작점을 만들지 않는다. 과거 자료가 일부라도 부족하면 관측 이력 없음으로 단정하지 않고 자료 부족으로 둔다.
- 스냅샷의 행 누락과 선택률0은 선택 미관측 근거이며 등장 불가·실측 선택0·전체 게임0으로 바꾸지 않는다. 패치별 최신 공개 게시본 하나만 사용하므로 같은 패치의 반복 갱신을 여러 패치로 세지 않는다.
- 순수 계산 helper·서버 조회·공개 read guard API·지연 로딩 UI를 연결하고 각 경계를 테스트한다. UI는 한 행에 한 증강, 검색·관측 상태 필터, 기준 패치와 조회 범위를 표시한다.
- 단일 패치 자료만 있는 실제 로컬에서 과거 미관측 날짜를 만들지 않는지 확인하고, fixture의 관측 중단·자료 누락·출처 변경 및 모바일 3종·데스크톱을 검증한다.
