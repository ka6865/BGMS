# 칭호 보류 개선안

상태: 당시 진단과 승인된 방향성 기록. 후속 구현·검증은 `2026-10-29-role-pending-implementation.md` 및 `../operations/2026-10-29-role-pending-validation.md`를 따른다. 아래 수치는 구현 전 기준이다. 당시 제품 코드/PR/운영 배포는 변경하지 않았다. 현재 PR #380의 `3a6fa81d`와 저장된 개발 관측을 기준으로 분석했다.

## 목표

칭호의 근거 조건을 유지하면서, 대표 역할을 하나로 확정하기 어려운 사람에게도 관측된 플레이 정보를 전달한다. 근거가 있는 복합 성향, 상위 역할 확정 기준 미달, 비교 불가, 실제 자료 부족을 같은 보류 문구로 처리하지 않는다.

## 보류 187건의 실제 구성

기존 개발308프로필을 재분석해 확정121/보류187을 그대로 재현했다. 최소 관측 조건 때문에 이전 단계에서 제외된5계정은 이308개에 포함되지 않는다. 새 독립 검증이 아니다.

| 분류 | 건수 | 의미 |
| --- | ---: | --- |
| 경기 구성에 따라 대표 역할이 변함 | 101 | 기존 정적 판정은 역할을 부여했지만 경기 창 검사에서 보류 |
| 단일 특화 역할/균형형 모두 확정하기 어려움 | 86 | 모든 역할이85 미만이고 최고~최저 차가25를 초과 |
| 모든 비교 기준 부재로 인한 보류 | 0 | 일부 역할 CDF 부족은 존재하지만 이번187건의 직접 분류 사유는 아님 |

86건 중 비교 가능한 역할이4개 미만인 경우는0건이고,79건은8~10개 역할을 비교할 수 있었다. 따라서 이들을 일괄적으로 “기록이 부족합니다”라고 안내하면 부정확하다.

추가 관측:

- 불안정101건 중27건은 기준 시점 상위 두 역할이 모두85 이상이며, 현재 경기 창 변형의80% 이상에서 대표가 그 두 역할 안에 있었다. 단일 순위 대신 복합 성향으로 설명할 후보이다.
- 나머지 사유 집단86건 중47건은 확정 기준에 못 미쳐도 최상위 후보 방향이 현재 변형의80% 이상에서 유지됐다. 대표 칭호 부여와 관측 성향 설명을 구분할 필요가 있다.
- 불안정101건 중8건은3회 이상 변형에서 서로 다른 모드/경기 유형이 섞였고,15건은 유효 적중/경기 최소 조건을 잃는 변형이 있었다. 서로 겹칠 수 있는 진단값이며 별도 합산하지 않는다.
- 27+47은 서로 다른 원인 집단의 후보74건이다. 74건의 칭호를 확정할 수 있다는 뜻이 아니다. 현재 최대10개 변형에는 선정되지 않은 경기의 제외처럼 결과가 그대로인 변형도 들어 있어, 후속 검증에서는 실제 선정 구성이 변하는 경우도 별도로 보고해야 한다.

## 권장하는 처리

### 1. 대표 칭호와 성향 요약을 구분

- 대표가 충분히 확인되면 현재처럼 칭호를 표시한다.
- 대표를 확정하지 못해도 관측값이 있으면 상단에는 짧은 성향 요약을 표시하고, 작은 상태 설명으로 대표 칭호 미확정을 알린다.
- 성향 요약은 실제 거리별 피해·구조 성공/기회·팀 피해 비중 등으로 만든다. 단순 최고 점수의 역할명을 낮은 기준으로 발급하지 않는다.
- 원본 범위와 분모를 함께 표시한다. 다른 플레이어 대비 강함/상위권/전문가를 추론하지 않는다. 미관측을0으로 채우지 않는다.

KangHeeSung_의 현재 선정5경기 예시: 유효 거리 관측 피해 중50m 미만68.7%, 팀 피해 비중의 경기별 평균55.8%. “근거리 교전 중심 — 근거리 피해 약69%”처럼 사실을 설명할 수 있다. 대표 칭호가85를 넘지 않았다는 이유로 이 정보까지 숨길 필요는 없다. 이 숫자는 최근 전체10경기 평균이 아니다.

### 2. 강점 두 개의 순서만 바뀌면 복합 성향 검증

- 기본적인 두 역할의 필수 근거와85 기준은 모두 유지한다.
- 이름 순서가 아닌 역할 집합의 안정성도 검사한다. 두 역할 안에서만 대표 순위가 바뀌는 경우는 별도 검증한다.
- 처음에는 “근접·원거리 복합 성향” 같은 관측 요약으로 표시한다. 새 복합 칭호를 확정하기 전에는 해당 두 역할의 참고 분포 불확실성·유효 표본·실제로 바뀐 경기 구성에서도 안정적인지 확인한다.
- 세 개 이상 역할이 오가거나 핵심 근거가 사라지면 단일/복합 칭호를 강제하지 않는다.

MiaeQ_Q는 현재 주 역할인 근접을 유지하면서 원거리 타격 기록을 보조 설명으로 전달할 수 있다. 원거리 보조 역할의 순서가 흔들린다는 이유로 전체 분석을 비우지 않는다.

### 3. 판정 자격과 경기 창 검사의 불필요한 제약 교정

- 동일 raw mode/TPP·FPP/일반·경쟁 안에서 비교한다. 혼합 모드 때문에 비교 불가해진 변형을 실제 플레이스타일 변화와 구분한다. 동일 조건 안의 유효 경기·변형 수가 충분할 때 재판정한다.
- 현재 모든 역할에 걸린 총기 유효 적중6회 공통 조건은 역할별로 재검토한다. 구조·투척 역할은 해당 행동의 기회와 관측으로 판단하고, 총기 교전의 부족만으로 전체를 보류하지 않는 후보를 검증한다.
- 실제 팀원 없는 경기 하나 때문에 다른 정상 팀 경기의 모든 역할을 잃는 경우도 검증한다. 팀 역할은 실제 팀 경기/기회에 맞춘 분자·분모를 사용하되 부족한 역할만 보류한다.
- 한 경기의 활약에만 의존하거나 어떤 역할도 최소 관측 조건을 충족하지 못하면 근거 수집 중을 유지한다.
- 위 변경은 모집단 정의가 달라지므로 기존 CDF를 재사용하지 않는다. 개발 자료에서 역할별 조건을 고정하고 새 분포·독립 확인을 함께 준비한다.

### 4. 분석 경기 수 확대는 별도 실험으로 유지

같은 조건의 최근 경기만 남긴270프로필에서 상위5와 최근 최대10의 CDF를 각각 다시 학습한 탐색 비교도 수행했다. 학습·holdout·타깃 계정은 두 실험에서 같게 유지했다.

| 조건 | 상위5 대표 유지 | 최대10 대표 유지 | 상위5/최대10 참고 분포 재표집 일치 |
| --- | ---: | ---: | --- |
| 듀오 경쟁87프로필 | 33 | 38 | 79.25% / 75.75% |
| 스쿼드 경쟁89프로필 | 33 | 33 | 81.53% / 80.03% |
| 스쿼드 일반94프로필 | 35 | 36 | 73.07% / 73.43% |

대표 유지101→107로 변화가 작고 분포 재표집 안정성이 모두 좋아진 것도 아니다. 따라서 현재 자료만으로 최대10 전환을 채택하지 않는다. 위270명의 결과를 원래308명/121개 결과와 직접 비교하지 않는다. 잠재 티어의 상위5 기준도 이번 개선안에서 바꾸지 않는다.

## 구현·검증 순서

1. 서버 판정 사유를 명확히 구분하고 기존 `RoleInfo.status/reason/description/evidence`와 실제 표시 범위를 연결한다. 전체 보류 카드의 공백부터 없앤다.
2. 강한 두 역할의 집합 안정성과 관측 성향 요약을 로컬 후보로 추가한다. 확정 칭호·복합 관측·단일 성향·근거 부족을 구분한다.
3. 모드 혼합과 공통 총기 조건, 팀 기회 분모로 인한 보류를 별도 후보로 검증한다. 효과를 구분할 수 있도록 한꺼번에 기준을 튜닝하지 않는다.
4. 새 의미가 바뀐 지표/역할 CDF만 다시 만들고, 기존 학습50/holdout20과 지정 계정 학습 제외를 유지한다. 별도 계정·개발 경기 비중복의 새 최종 확인 표본을 고정한다.
5. 원인별 보류율, 설명 가능한 비율, 단일·복합·성향 표시 비율, 실제 구성 변경과 참고 분포 재표집의 안정성을 각각 보고한다. 보류율 목표를 맞추려고85/80을 낮추지 않는다.

수정 연결부는 `roleClassifier.ts`, `referenceCalibration.ts`, `summaryAggregate.ts`, `RecentAISummary.tsx`, `ai-summary/route.ts`다. AI 전달 문구도 확정 상태가 아닌데 “부여된 칭호”라고 쓰지 않도록 구분한다. UI와 AI의 표현을 한 서버 판정에 맞춘다. 상태 변경을 캐시할 때에는 새 규칙/캐시 identity를 함께 검증한다.

별도 UI 라이브러리·LLM 판정·DB 스키마를 추가할 필요는 없다. 로컬 관측과 기존 순수 함수로 만든다. 구현 시 core/analysis/단위 회귀와 기존 fixture의375x667·390x844·430x932·데스크톱 검증을 수행한다. 이번에는 조사와 준비안만 작성했으며 제품 테스트를 다시 실행한 것으로 보고하지 않는다.

## 아직 확인하지 않은 것

복합 성향 후보27건과 안정적인 후보 방향47건은 새 표시 가능성을 찾은 개발 진단이며 실제 개선 효과나 정답률 검증이 아니다. 특히 원본 기준 분포의 불확실성과 새로운 독립 검증은 남아 있다. bgms.kr 운영과 기존 PR은 변경하지 않았다.
