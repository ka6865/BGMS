# 증바람 챔피언 선택 통계 공개 화면

**목표:** 기존 `/lol/kr/aram-mayhem`에서 챔피언을 고르고 수집된 증강 선택 통계를 바로 읽는다. 사용자 요청과 직전 설명의 챔피언 검색·선택률순·등급 필터·아이콘·효과·출처 표시를 구현한다.

**구조:** 기존 공개 API와 `LolMayhemChampionStats`를 재사용한다. 증강 도감과 챔피언 통계는 같은 페이지의 보기 전환으로 구분하며 통계를 기본 화면으로 연다. 별도 상세 페이지·의존성·통계 계산식을 추가하지 않는다.

## 작업

- [x] 기존 브라우저 하네스에 기본 진입·정렬·검색·등급·초기화·늦은 응답 테스트를 추가한다.
- [x] `LolMayhemChampionStats`에 챔피언 검색, 초기 챔피언, 증강 검색·등급 필터, 선택률순 아이콘·효과 목록을 적용한다. null은 0과 구분하고 필터에서 숨겨도 출처 정보를 유지한다.
- [x] `LolMayhemView`에 통계/도감 보기 전환을 추가한다. 기존 도감 필터와 해외 조합 영역은 보존한다.
- [ ] 기존 관리자 인증·승인·공개 경로로 후보 #1을 검증한다. 원본·비밀키는 공개하지 않고 API allowlist와 검수 이력, 충돌 감지, 패치 일치를 보존한다.
- [ ] `verify:core`, `verify:lol`, 기존 브라우저 하네스의 375×667·390×844·430×932·1440×900을 검증하고 로컬 서버와 실제 데이터 화면을 사용자에게 보여준다.

## 확인할 경계

- 0%는 표시하고 미제공은 마지막에 둔다. 선택률은 출처가 제공한 비율이며 승률·등장 확률로 바꾸지 않는다.
- 챔피언 전환 시 이전 챔피언의 응답이 덮어쓰지 않는다. 검색 결과 없음, 통계 없음, 오류/재시도 상태를 제공한다.
- 현재 카탈로그에 없는 증강은 ID로 표시하고 설명·등급을 추측하지 않는다.
- 이전 패치 자료는 이전 패치로 표시한다. 승인되지 않은 후보를 공개 읽기로 우회하지 않는다.
