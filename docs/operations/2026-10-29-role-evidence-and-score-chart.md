## 재현과 보관

개인 입력/재생 스냅샷은 Git 밖 private 보관소에 gzip·SHA256 manifest와 함께 저장한다. 공개 JSON은 익명 cohort 집계·후보 CDF·두 지정 사례만 포함한다. 원본 전체를 장기 보관했다고 주장하지 않는다.

최종 고정 개발 입력을 해제해 다음 읽기 전용 CLI로 원본 재생을 재현한다. source-dir은 실제 보관된 shared-source 디렉터리를 반복 지정한다. 이 명령은 운영 DB/API/R2에 접근하지 않는다.

```bash
node --import tsx scripts/audit_role_evidence.ts \
  --input /private/combined-input.json \
  --source-dir /private/shared-sources \
  --output /private/role-report.json --max-profiles 1000 \
  --snapshot /private/replayed-results.json.gz
```

일부 역할의 관측 부족, 참고 분포 재표집 민감도, 실제 이벤트의 희귀 중복, 새 독립 최종 확인은 운영 활성화 전 남은 검증이다. 후보 선택이나 문턱을 바꾼 뒤 이전 확인 표본을 미열람 검증이라고 표현하지 않는다.
