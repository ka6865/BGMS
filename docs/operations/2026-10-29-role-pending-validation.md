# 칭호 미확정 설명과 신규 역할 후보 검증

상태: PR #380의 개발 후보. bgms.kr 배포·main 병합·운영 DB/R2 쓰기·키 변경·캐시 삭제는 하지 않았다. 기존 계산5·점수·기본 CDF1·요약 API의 기본 분류는 유지한다. 새 정책은 `reference.evidenceVersion:2`와 `aggregateMatches(...,{roleEvidenceVersion:2})`를 명시한 경로에서만 사용한다. 개별 엔진 관측은 version1 그대로다.

## 결과의 의미

기존 개발 자료 313명·2,902전적을 확인했다. 같은 전적의 기존 benchmark 객체와 로컬 재생 결과를 비교한 차이는 0건이다. 기존 EV1의 유효 308명과 새 EV2의 유효 309명 중 공통 308명을 비교한다. 고정 seed·계정 분리·지정 계정 학습 제외를 유지했다. 이미 살펴본 개발 표본이며 새 독립 검증 또는 정답률 측정이 아니다.

| 공통 308명 판정 | EV1 | EV2 |
| --- | ---: | ---: |
| 확정 칭호 | 121 | 90 |
| 균형형 | 0 | 1 |
| 대표 미확정 + 복합 성향 설명 | 0 | 37 |
| 대표 미확정 + 실제 관측 설명 | 0 | 180 |
| 관측 설명 없는 보류 | 187 | 0 |

**대표 칭호의 보류는 187→217명으로 늘었다.** 변화 없는 경기 구성을 안정성 분모에서 제외했기 때문이다. 보류율을 낮췄거나 정확도가 높아졌다고 해석하지 않는다. 개선한 부분은 근거가 확인되면 보류 상태에서도 선정 경기의 실제 관측을 설명하는 것이다.

- 기존 확정121명: 85명 유지,16명 복합 관측,20명 단일 관측으로 전환.
- 기존 보류187명:5명 확정,1명 균형형,21명 복합 관측,160명 단일 관측으로 전환.
- 이전 총기 적중6회 조건에서 제외된5명도 로컬 원본으로 재생했다. 1명은 총기 적중이 없지만 상대별 교전0승3패의 관측을 설명할 수 있었다. 나머지4명은 역할 판정 기회가 없어 새 학습에서도 제외했다. 이5명을 공통308명에 섞어 개선율을 계산하지 않는다.
- EV2 전체309명은90명 확정·1명 균형형·37명 복합·181명 단일 관측이다. 미확정218명은 여전히 확정 칭호가 아니다.

계산 근거·분포·기회 수·전환 집계는 [JSON](2026-10-29-role-pending-validation.json)에 있다.

## 적용한 계약

- 구조는 구조 성공/실제 기회,거리 역할은 좌표가 확인된 본인 피해300 이상,교전은 기존 최소 교전 수를 사용한다. 투척 후보는 피해형 투척3회·연결 적중1회 이상이다. 모든 역할에 총기 적중6회를 공통 적용하지 않는다. 행동 기회가 없는 프로필은 `no_role_opportunities`로 학습에서 제외한다.
- 팀 역할은 실제 roster>1 경기의 분자·분모를 사용한다. 역할에 필요한 팀 지표가 일부 누락되면 그 역할만 판정하지 않는다. 미관측을0이나100으로 채우지 않는다.
- EV2는 유효 최근 최대10경기에서 최고 점수 경기의 cohort를 기준으로 같은 raw mode·TPP/FPP·일반/경쟁만 남겨 best5를 선정한다. 참고 분포에도 cohort를 보존한다. 최소3경기,지표/역할별 학습50명·개발 holdout20명,원정밀도85,안정성80% 조건은 낮추지 않는다.
- 경기 창 안정성은 best5 구성이 실제로 바뀌는 변형만 센다. 최소3회 비교가 필요하다. 필수 기록 부족과 대표 순위 변화의 보류 사유를 구분한다. EV1의 기존10회 검사와 분모가 다르다.
- 두 역할이 기준 시점에서 각각85 이상이고 실제 변형의80% 이상에서 대표가 두 역할 집합 안에 머물면 복합 성향으로 설명한다. `status:pending`과 `primaryRole:pending`을 유지한다.
- `presentation`은 확정/균형형의 `role`,미확정의 `observed`/`combined`,자료 부족의 `insufficient`로 구분한다. 거리 성향은 본인의 관측 피해 과반을 기준으로만 표현하며 비교 상위권·실력·의도를 추론하지 않는다. 실제 선정 경기 수와 분모를 표시한다.
- UI 상단과 상세는 서버의 성향 이름·설명·보류 사유를 사용한다. AI에는 관측 성향을 ‘부여된 칭호’나 ‘완성형’으로 전달하지 않는다. presentation 없는 기존 문구는 유지한다.
- 감사 입력도 프로필과 같은 기대 ID·현재 버전·계정 필터를 거친다. 제외한 다른 계정/구버전 고득점 경기가 안정성이나 중거리 후보에 다시 들어오지 않는다. 리뷰에서 재현한 이 문제는 회귀 테스트로 수정했다.

## 지정 계정

두 계정 모두 학습에서 제외했다. 실제 운영 응답이 아닌 저장된 개발 경기의 결과다.

| 계정 | EV2 설명 | 선정5경기의 거리 확인 피해 비중 |
| --- | --- | --- |
| KangHeeSung_ | 근거리 교전 중심,대표 칭호 미확정 | 50m 미만68.7%,50–200m28.2%,200m 이상3.1% |
| MiaeQ_Q | 근거리 교전·원거리 교전 복합 성향,대표 칭호 미확정 | 50m 미만87.0%,50–200m0%,200m 이상13.0% |

MiaeQ_Q의 대표 유지율은 예전10개 변형의80%에서 실제 구성 변경5개 변형의60%가 됐다. 두 역할 집합의 관측 설명을 남기며 단일 대표를 강제로 유지하지 않는다. 복합 성향은 두 거리의 피해량이 같다는 뜻이 아니다.

## 중거리 정식 칭호를 추가하면

50m 이상200m 미만 피해 비중을 별도 지표 CDF→역할 CDF로 학습했다. 본인 피해 과반·85 이상·기존 역할보다 높은 점수·실제로 바뀐 변형3회 이상과80% 조건을 기준과 변형 모두에 적용했다. 기존 지휘관의 역할 수에는 더하지 않았다.

| EV2 cohort | train/holdout의 유효 거리 표본 | 안정 후보 | 기존 미확정에서 추가 포착 |
| --- | ---: | ---: | ---: |
| 듀오 경쟁 | 68/28 | 6 | 5 |
| 스쿼드 경쟁 | 70/35 | 3 | 2 |
| 스쿼드 일반 | 68/33 | 2 | 2 |

추가 포착은 총9명으로 현재 미확정218명의 약4.1%다. 이 중8명은 학습 계정이고 개발 holdout은1명뿐이다. 안정 후보11명에는 기존 확정 대체1명과 균형형1명도 포함된다. 따라서 정식 칭호 추가만으로 보류가 크게 줄어든다고 판단할 근거는 부족하다.

안정 후보의 기존 최고 역할과 겹치는 수는 원거리 역할4명·처형자1명·근접 역할0명이다. 이는 최고 기존 역할과의 겹침 집계이며 상관계수나 역할의 독립성 검증이 아니다. 두 지정 계정은 자기 중거리 피해 과반 조건에 미달한다.

동점 구간은 기존 `referencePercentile`/`roleScorePercentile`을 재사용했다. 초기 탐색의 ‘최대12명’ 수치는 동점·변형별 자격을 다시 확인한 위 결과로 대체한다. 신규 중거리 `RoleKey`는 제품에 추가하지 않았다. 별도 독립 표본과 새 역할 분포의 재표집 검증이 남았다.

## 검증

- Node24.22.1,`verify:core`:0오류·기존49경고.
- 집중6파일:381통과. `verify:analysis`:703통과·6skip.
- 전체 `test:unit -- --maxWorkers=2 --testTimeout=15000`:5,679통과·227skip·1실패. 기존 `calibration-acquisition`의 소스 복구 테스트가 실제 로컬 디스크 부족으로 `stoppedReason:low_local_disk`를 반환했다. 이 가드를 우회하거나 무관한 테스트를 변경하지 않았다. 전체 통과로 보고하지 않는다.
- 격리된 실제 브라우저20개 통과:375x667·390x844·430x932·1440x900에서 상태,긴 성향명,수치,요청/identity,넘침을 확인했다. 긴 실제 형식의 거리 설명은4개 뷰포트에서 추가 재확인했다. 최초 실패는 상세 펼침의 가시성 대기 누락,다음 실행 중단은 Chrome 임시 디렉터리 ENOSPC였으며 수정/재실행 후 통과했다.
- 독립 코드 리뷰의 Important1건은 기대 ID·계정·현재 버전 필터 공유와 오염 입력 회귀로 수정하고 재검토받았다.
- 새 독립 최종 표본,실제 Gemini,실기기/Capacitor,운영 배포는 검증하지 않았다. EV2 참고 분포 재표집의 제목 일치율은 듀오 경쟁73.66%·스쿼드 경쟁83.89%·스쿼드 일반78.63%로 모두80%를 넘지는 않는다. 기존 기준을 운영에서 교체할 근거로 사용하지 않는다.


개인 ID·경기 원본·재생 스냅샷은 Git에 넣지 않는다. 입력 SHA256은 결과 JSON에 보존한다. 지속 보관본과 복원 명령은 원래 작업 폴더의 `docs-private/coaching-role-evidence-2026-10-29`에 둔다. 하위 워크트리에는 `docs-private/`와 보조 rules가 없어 추적된 문서·실제 코드·테스트를 기준으로 구현했으며, 부모의 관련 로컬 규칙도 확인했다.
