# AI SDK 업데이트와 오류율 점검 (2026-11-12)

## 측정 범위

- 운영 Supabase `ai_usage_logs` 읽기 전용 조회. 기준 시각은 **2026-11-12 04:33:42 KST**이며, 7일 범위는 11월 5일 04:33:42부터다.
- 조회 254행 중 동일 `request_id`의 스쿼드 성공·실패 중복 1행을 합쳐 253요청으로 계산했다. 실패를 최종 결과로 사용했다. 부분 완료는 실패에 넣지 않았다.
- 아래 분모는 기록된 요청이며 캐시 적중과 생성 전 차단을 포함한다. 인증 실패 등 기록되지 않는 요청까지 포함한 전체 HTTP 오류율은 아니다. 모델 호출의 실패율과 응답 내용의 사실 오류율도 구별한다.
- 원격 DB·스토리지 쓰기, 캐시 삭제·재생성, 실제 사용자 데이터 외부 AI 전송, 배포는 수행하지 않았다.

## 변경 사항

- `ai`: `6.0.319` → `6.0.330`, `@ai-sdk/google`: `3.0.140` → `3.0.145`. 기존 주 버전을 유지하고 필요한 하위 SDK 의존성만 갱신했다. `@google/generative-ai`는 확인된 최신 `0.24.1`을 유지했다.
- 요약은 `OTHER` 후 재생성 전에 이전 응답을 비운다. 모든 후보가 실패해도 이전 응답을 다시 검증·저장하던 경로를 막고, 후보 응답 자체가 없으면 `model` 실패로 기록한다.
- 스쿼드는 출력 검증 뒤에만 성공을 기록한다. JSON 검증 실패는 실제 모델·토큰을 보존한 실패 한 행으로 기록하며, 성공·실패 저장 Promise를 기다린다. 공급자가 usage를 생략해도 성공 결과와 0토큰을 남긴다.
- 계산, 프롬프트, 캐시 identity와 UI는 변경하지 않아 캐시 버전을 올리지 않았다.

## 모델 확인과 선택

실제 키의 모델 목록 API에서 `gemini-3.8-flash`를 확인했다. 합성 PUBG 수치만 넣은 짧은 JSON 요청으로 새 SDK streaming을 비교했다(각 1회, 전체 코칭 품질 검증 아님).

| 모델 | 첫 텍스트 | 완료 | JSON |
| --- | ---: | ---: | --- |
| `gemini-3.5-flash-lite` | 1.024초 | 1.216초 | 통과 |
| `gemini-3.6-flash` | 5.493초 | 5.916초 | 통과 |
| `gemini-3.8-flash` | 15초까지 없음 | 15초 제한 종료 | 생성 미완료 |

기존 3.5 Flash-Lite는 구형 SDK streaming도 3.963초에 정상 완료했다. 3.8 Flash는 현재 모델별 응답 시작 제한 8초와 맞지 않는 결과이므로 공용 fallback 풀에 추가하지 않았다. 3.5 Flash-Lite → 3.1 Flash-Lite → 3.6 Flash 순서를 유지한다. AI SDK 7/Google provider 4 주 버전 전환과 구형 SDK 전체 교체는 이번 패치에서 제외했다.

공식 근거: [Google 모델 목록](https://aistudio.google.com/docs/models), [3.8 Flash 사양](https://aistudio.google.com/docs/models/gemini-3.8-flash), [AI SDK 릴리스](https://github.com/vercel/ai/releases/tag/ai%406.0.330), [Google provider 릴리스](https://github.com/vercel/ai/releases/tag/%40ai-sdk%2Fgoogle%403.0.145).

## 후속 확인

배포 후 같은 기간·분모로 `parse`, `finishReason=other`, `first_part:`와 동일 `request_id` 중복 수를 비교해야 한다. 이번 로컬 검증은 운영 오류율 감소를 증명하지 않는다. UI 변경이 없어 모바일 뷰포트 검증은 실행하지 않았다.
