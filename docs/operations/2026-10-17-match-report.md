# 경기 흐름·경기 전체 판정과 최근 세션 — 2026-10-17

## 목적

경기 상세에 "어떻게 죽었고, 교전마다 결과가 어땠는지"를 보여 준다. PUBG Lookup과 PUBG Meta가 제공하는 사망 유형·교전 결과·킬 트리·세션 묶기를 우리 텔레메트리 기준으로 다시 정의했다. 경쟁 사이트 코드는 가져오지 않았고 기능 구성과 기준만 참고했다.

## 저장 위치와 버전

- 분석 엔진이 `MatchReportCollector`(`lib/pubg-analysis/matchReport.ts`)로 이벤트 패스를 함께 관찰해 결과의 선택 필드 `matchReport`에 넣는다(`MATCH_REPORT_VERSION` 1).
- 개인 판정(착지·교전·사망·자기장·회복)은 내 사망 전 이벤트로 끝난다. 킬 트리·보급은 라이트 모드의 전멸 후 컷오프와 무관하게 모든 이벤트에서 모은다.
- `RESULT_VERSION`, `ANALYSIS_CALCULATION_VERSION`, `TELEMETRY_VERSION`은 올리지 않았다. 새로 분석하는 경기부터 채워지고, 예전 결과는 섹션을 숨긴다. 버전을 올리면 14일이 지난 경기는 텔레메트리가 없어 다시 계산할 수 없다.
- 실제 경기 두 판에서 리포트 크기는 17~18KB였다(대부분 킬 목록과 팀 순위).

## 판정 기준

| 항목 | 기준 |
| --- | --- |
| 착지 | 내 첫 `LogParachuteLanding` 기준 300m·600m 안에 처음 착지한 다른 팀 선수 수 |
| 교전 | 우리 팀과 적 팀 사이 전투 피해(자기장·출혈·낙하·익사 제외)·기절·처치를 30초 공백으로 나눈 묶음. 리플레이 "다음 교전"과 같은 `FIGHT_GAP_MS` |
| 교전 결과 | 적만 쓰러짐 = 승리, 양쪽 = 맞교환, 우리만 = 패배, 아무도 안 쓰러짐 = 이탈. 쓰러짐은 기절·처치를 선수별 한 번으로 센다 |
| 사망 유형 | 아래 순서로 첫 조건을 쓴다 |
| 자기장 | 새 흰 원(`poisonGasWarningRadius` 변경)이 정해질 때 내 마지막 위치가 원 밖이면 떨어진 거리(m) |
| 회복 | 내 체력 관측(위치·`LogHeal`)의 상승 합. 부활 직후 상승은 뺀다. 치료·부스트 횟수는 `LogItemUse`의 `subCategory`(Heal/Boost) |
| 교전 중 치료 | 교전의 첫 피해와 마지막 피해 사이에 쓴 치료 아이템 |

사망 유형 순서:

1. 자기장: 처치 피해 원인이 자기장
2. 출혈사: 기절 뒤 출혈 피해로 사망
3. 써드파티: 사망 전 60초 안에 우리 팀과 싸운 적 팀이 2팀 이상
4. 이동 중 잡힘: 마지막 교전 시작 전 30초에 150m 넘게 이동했거나 차량 안
5. 기습 당함: 킬러 팀이 먼저 쐈고 우리 팀이 킬러 팀에 준 피해가 100 미만
6. 고립: 사망 순간 가장 가까운 생존 팀원(최근 30초 위치)이 100m 초과
7. 정면 교전 패배: 위에 해당하지 않음

## 텔레메트리 한계

- 분석용 텔레메트리 계약은 보급 상자 내용물(`itemPackage.items`)과 `LogItemPickupFromCarepackage`, `LogHeal.healAmount`를 담지 않는다. 그래서 보급은 종류·페이즈·시각만 보여 주고, 회복량은 체력 관측 상승으로 계산한다. 계약을 넓히면 분석 캐시 형식이 바뀌므로 이번에는 손대지 않았다.
- 킬 트리는 마지막 처치 기준이다. 부활 뒤 다시 죽은 선수는 마지막 처치만 쓰고, 순환으로 루트가 끊긴 처치자는 별도 루트로 붙인다.

## 최근 세션

`lib/stats/recentSessionOverview.ts`는 최근 20경기 요약과 같은 경기 집합을 시작 시각순으로 정렬하고, 앞 경기와 60분 넘게 벌어지면 새 세션으로 나눈다(PUBG Meta와 같은 기준). 가장 최근 세션의 경기 수·우승·킬·평균 피해·최고 순위·경기별 킬과 그 세션에서 2판 이상 함께한 팀원을 데스크톱 왼쪽 열에 보여 준다.

## 리플레이

- 2D 리플레이에 보급 상자 착지 위치를 그린다(착지 뒤 계속 표시, 20초 동안 이름표).
- 스페이스 재생/정지, 좌우 방향키 5초, Shift+방향키 30초 이동. 입력 칸과 포커스된 버튼에서는 기본 동작을 막지 않는다.
- "링크" 버튼은 현재 주소에 `t`(초)를 붙여 복사한다. 경기 흐름의 교전 줄 "리플레이"도 같은 `t`로 교전 3초 전부터 연다.
