# 수집 불가 전적의 기간 만료 구분

`not_found`는 PUBG 조회의 404 또는 계정 정보 없이 조회한 응답에서 대상 참가자를 찾지 못했다는 뜻이다. 모든 `not_found`를 기간 만료로 단정하지 않는다.

공통 수집 worker는 기존 저장 확인 후 PUBG를 조회한다. 실제 404를 받았고 최초 발견일부터 14일 이상 지난 작업은 `unavailable / discovery_window_elapsed`로 마무리한다. 최초 발견일은 실제 경기일이 아닌 경기일의 상한이므로 별도 코드로 구분한다. 오래된 ID도 정상 응답과 유효한 기본 전적을 얻으면 저장한다. 날짜가 없거나 최근에 발견된 ID는 기존 첫 404 후 6시간 재확인 정책을 유지한다. 반복 404의 `unavailable` 작업은 재수집하지 않는다.

공식 응답에서 순위가 0인 `tutorialatoz` 또는 `tdm` 기록은 `unsupported_match`로 반환한다. 현재 기본 전적의 필수 순위 계약에 맞지 않으므로 가짜 순위를 저장하지 않고 `unavailable / match-placement-unavailable`로 제외한다. 실제 순위가 있는 TDM은 계속 저장하며, 일반 배틀로얄의 누락·비정상 통계와 일시적인 API·DB 실패는 재시도한다. 연결 계정 동기화도 이 결과를 건너뛰고 다음 경기를 처리하며 `unsupportedMatches`에 별도 집계한다.

2026-10-08 KST 운영 조사에서 `not_found` 14,560건의 원래 작업 행을 비공개 로컬 파일에 백업했다. 플랫폼·경기 ID별 유효한 계정 연결 기본 전적의 날짜가 일치하는 530건을 `retention_expired`로 구분했다. 실제 날짜가 없는 기록 중 최초 발견 후 14일이 지난 8,643건은 `discovery_window_elapsed`로 구분했다. 날짜 미확인 5,387건은 `not_found` 상태를 유지했다. 이 작업은 이미 제외된 수집 작업의 사유만 갱신했으며 기본 전적·개인 성과·R2 객체를 삭제하지 않았다.

별도 재시도 작업 8건은 공식 응답의 계정·경기 ID·원본 통계를 확인했다. 7건은 훈련, 1건은 생존 시간 3초·순위 0인 TDM이었다. 백업한 작업 스냅샷과 일치하는 행만 실행 시각을 앞당긴 뒤 기존 claim/lease/settle 경로로 처리하여 8건 모두 `match-placement-unavailable`로 제외했다. 실제 수집 성공으로 집계하지 않는다. 날짜 미확인 기록의 추가 공식 재조회 결과는 최종 실행 결과에 별도로 기록한다.
