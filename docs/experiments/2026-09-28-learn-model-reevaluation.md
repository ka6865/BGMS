# /learn 장면 선택 모델 재평가 — 2026-09-28

상태: 로컬 구현·검증 완료. 모델 품질 표는 균등한 2라운드 56 trial 기준이다. 한도 재검증으로 3개 trial을 추가 완료해 계획 84 중 현재 완료 59·미완료 25다. 65초 간격과 5분 무호출 대기 후에도 3.6·3.7·3.8은 429, Flash-Lite 대조군은 성공했다. **무료 일일 20회라는 이전 단정은 철회하며 실제 한도·리셋 주기는 미확인이다.** 현재 `gemini-3.5-flash-lite` 유지·교체 판단 보류, 운영 DB·배포·모델 설정 변경 없음.

## 이번 평가가 답하는 질문

같은 검증 근거에서 어떤 모델이 유효한 3~5개 장면을 고르는지 평가한다. 모델이 자유롭게 쓴 해설의 정확도나 가독성 시험이 아니다. 공개 상황·행동·결과는 코드가 만들기 때문에, 근거 없는 문장이 차단되는 효과와 모델의 선택 품질을 구분한다. [지난 자유 해설 비교](2026-09-24-gemini-flash-comparison.md)와 수치를 합산하지 않는다.

이전 비교에는 `facts`와 `LogPlayerRevive`가 빠져 있었다. 새 공통 입력에는 전체 근거, 원본 배열 인덱스, 인물·팀·무기·이벤트 종류가 포함된다. 실경기 원본의 01:36 VSS 피해, 02:59 기절과 03:12 처치, 13:38 소생을 다시 대조했다. 발사 무기 정규화, 재착지 ID 중복, 교전 좌표 cm/m, 차량 장면 제목도 통합 검증에서 수정했다.

## 지표 정의

원본 채택은 모델의 ID 목록을 수정 없이 게시할 수 있었던 trial이다. 대체는 중복 근거·역순·필수 종료 장면 누락 등을 검증기가 보완한 trial이다. 아래 완료 결과의 분모는 모델별 14 trial이며 호출 실패도 포함한다. 계획 21 trial/모델 중 3라운드 7건씩은 이 표의 분모 밖이다. 이 중 후속 재검증 3건과 아직 실행하지 않은 25건은 별도로 명시한다. 미완료를 성공·내용 실패로 간주하지 않는다.

커버리지는 각 경기에서 미리 지정한 착지·최초 교전·첫 소생(존재할 때)·경기 종료 근거 묶음 중 선택 장면이 포함한 비율의 경기/trial 평균이다. 원본 선택과 보완 후 게시 선택을 나눠 계산하며 호출 실패는 0으로 센다. 이 묶음은 재현 가능한 확인 기준이고 전술적 중요도의 유일한 정답은 아니다. 상황에 따라 이후 교전·다른 소생을 선택해도 유용할 수 있다.

인물·팀·시각·무기·이벤트 종류의 공개 내용은 원본 기반 생성 로직을 회귀 검사하고 7경기 출처를 감사했다. 모든 출력 문장을 사람이 독립적으로 전수 검토한 것은 아니므로 “모델 사실 정확도 100%”로 표현하지 않는다. 자유 산문 오류율·블라인드 가독성·학습 유용성은 미평가다.

## 비용·속도 해석

오류 응답에는 분당 입력 250,000토큰과 `GenerateRequestsPerDayPerProjectPerModel-FreeTier`, 값 20이 표시됐다. 그러나 같은 실행에서 해당 오류 이후 성공한 기록도 있어, 이 문구만으로 실제 계정이 무료이거나 하루 20회로 고정됐다고 확정할 수 없다. 이전의 일일 한도 단정은 철회했다. 시간 간격을 둔 재호출 결과는 아래에 기록한다. [공식 한도 안내](https://ai.google.dev/gemini-api/docs/rate-limits)는 RPM·TPM·RPD를 구분하고 실제 프로젝트 한도는 AI Studio에서 확인하도록 안내한다. 429와 서버 503은 모델 문장 품질 오류가 아니다. 캐시와 호출 시점이 다르고 중간 재개도 있었으므로 지연 순위를 일반적인 모델 성능 순위로 해석하지 않는다. 표의 중앙값·p95는 각 trial 내 대기·재시도를 포함하며 중단 공백은 제외한다.

비용은 응답 usage가 있는 시도를 유료 표준단가로 환산한 참고값이다. 실제 청구액이 아니며 실패 요청의 사용량은 반환되지 않아 포함하지 못했다. 3.5 Flash-Lite는 입력/캐시/출력·thinking 100만 토큰당 $0.30/$0.03/$2.50, 3.6·3.7·3.8 Flash는 2026-12-31까지 $0.75/$0.075/$3.75를 적용했다. 명시적인 캐시 저장 리소스는 만들지 않았다. [공식 요금표](https://ai.google.dev/gemini-api/docs/pricing)

예비 실행은 정식 표에 합산하지 않는다. 첫 실행은 차량 제목 오류로, 두 번째는 서버 대기시간을 무시한 짧은 재시도로 중단했다. 예비 기록은 보존했고 요청 수·환산 비용을 별도로 남긴다.

## 한도 해석 정정과 시간 간격 재검증 (2026-09-28 KST)

사용자 지적 후 원본 로그를 다시 대조했다. **“무료 일일 20회 한도로 더 실행할 수 없다”는 이전 결론은 철회한다.** 오류의 quota ID·값은 관측된 응답 필드이며, 실제 계정 등급·프로젝트 한도의 독립 확인이 아니다.

동일 trial에서 해당 오류 이후 성공한 5건이 있었다. 최초 요청부터 성공까지 3.6은 17.651초, 3.7은 127.892·128.907초, 3.8은 57.885·103.712초였다. 날짜 변경을 기다려야 한다는 단정과 모순된다. 한편 이 사실만으로 모든 429가 분당 제한이라고 단정하지도 않는다.

첫 재검증은 같은 `.env.local` 키·고정 입력·공통 호출 함수로, 3.6·3.7·3.8 각각 시작 시각 기준 최소 65초 간격으로 3회씩 실행했다. 외부 환경변수가 키를 덮어쓰지 않음을 값 노출 없이 확인했다. 9회 모두 429였다. 이 3개 trial은 원본 로그의 3회차에 추가됐으며 위 표의 균등한 2라운드 56건에는 섞지 않았다.

실제 무호출 대기는 **300.286초**였다(KST 06:38:38~06:43:38). 같은 솔로 입력의 재호출 결과:

세 실패 응답은 여전히 같은 quota ID와 값 20을 반환했다. 이는 **현재 해당 모델의 호출 제한이 남아 있음**을 보여주지만, 실제 계정 등급·정확한 리셋 주기까지 확인한 것은 아니다. 5분보다 긴 대기에서의 복구 여부는 미확인이다. 본 프로젝트 키와 운영 GitHub secret의 일치 여부·AI Studio의 활성 한도도 확인하지 않았다.

원본 비교 로그는 후속 9시도를 포함해 94시도·59개 trial summary가 됐다. 5분 후 대조 호출 4건은 `cooldown-recheck.jsonl`에 별도로 보관하며 품질 표에 섞지 않는다. 추적 JSON의 `cooldownVerification`에 요청 시각·응답 코드·대기 길이·usage를 기록했다. 변경한 것은 한도 해석과 실험 기록이며, 고정 입력·추출기·모델 호출 설정은 바꾸지 않았다.

- 운영 DB 적용·배포·운영 모델 전환은 수행하지 않았다. 새 앱 적용 전 모드별 PK 마이그레이션이 필요하다. [운영 문서](../daily-ranker-story.md)

## 사람이 이어 평가할 기준

모델명을 가린 동일 경기의 장면 카드에 가독성·학습 유용성을 각각 1~5점으로 평가한다. 1점은 흐름/점검할 행동을 파악할 수 없음, 3점은 이해되지만 설명 보완이 필요함, 5점은 추가 설명 없이 흐름과 다음 경기의 점검 항목을 말할 수 있음으로 둔다. 점수와 함께 문제가 된 장면 ID와 이유를 적는다. 현재 이 점수는 수집하지 않았다.
