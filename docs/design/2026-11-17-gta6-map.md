# GTA6 서브 지도

사용자가 승인한 첫 버전: BGMS `/gta6`에서 한국어 장소 검색, 분류 필터, 장소 선택, 즐겨찾기, 방문 체크와 선택 장소 URL 공유를 제공한다. 기존 PUBG·LoL 화면은 보존한다.

기존 BGMS의 어두운 배경·선명한 텍스트·44px 이상 터치 영역을 따른다. 데스크톱은 왼쪽 장소 목록과 오른쪽 지도를 배치하고 모바일은 지도 아래 검색·장소 패널을 둔다. 긴 목록과 상세 정보는 패널 안에서 스크롤한다. 지도는 첫 화면의 중심이며 홍보 화면을 추가하지 않는다.

GTADB의 commit을 고정한 YANIS v17 타일과 원본 JSON을 자체 정적 파일로 보관한다. Leaflet CRS.Simple에 좌표와 줌을 맞춘다. 데이터 파서는 잘못된 행을 거부하고, 좌표 없는 장소를 지도에서 제외하며, 미확인 매칭은 명시한다. 한국어 검색 별칭과 분류 번역은 원본과 분리한다.

사진과 3D, 회원 동기화, 제보·운영 DB 쓰기는 첫 버전 범위에 없다. 진행도는 이 브라우저에 저장한다. 저장소 사용이 불가능하면 화면에 알리고 메모리 상태는 유지한다. 원본 지도·장소는 추정 정보를 포함하므로 공식 지도처럼 표시하지 않는다.

검증: 데이터 경계·좌표/타일 대응·필터·저장 데이터 검증, 공용 레이아웃 경로 회귀, verify:core, test:unit, 모바일 375x667·390x844·430x932 및 데스크톱 브라우저.
